# 実例が1件しかない9型の白文 — 収集と検収の記録（進行中）

依頼パックは `docs/gemini-pack-kuho-9types.md`。
**ただし第1回は Gemini に投げず、こちら側で維基文庫の原文に直接あたって集めた。**

## なぜ自分で集めたか

前回（`material-kuho-4types.md`）で分かったのは、**報告のうち検収に耐えたのは半分**で、
落とした4件はどれも**原文にあたれば1回で分かる**種類の誤りだった（不在2件・句形違い1件・句読1件）。
訓点欄も4件中3件が誤っていた。つまり**この作業の実質は「原文にあたること」**で、
そこができるなら伝言を1回減らしたほうが速く、落ちる情報も無い。

**やり方**: `https://zh.wikisource.org/w/index.php?title=<頁名>&action=raw` で
**生のウィキテキストを取り、一字一句そのまま抜き出す**。整形済みの頁を要約させると
文字列が変形するので、必ず `action=raw` を使う。
（`ctext.org` は CAPTCHA で止まるので使わない。**CAPTCHA は突破しない**）

## 第1回（2026-08-13・v48）— 4問・3型

| 型 | 白文 | 出典 | 問題ID |
|---|---|---|---|
| 抑揚 `yokuyo-nao` | 蔓草猶不可除況君之寵弟乎 | 春秋左氏伝 隠公元年 | `saden-mansou` |
| 抑揚 `yokuyo-nao` | 布衣之交尚不相欺況大国乎 | 史記 廉頗藺相如列伝 | `kanpeki-fui` |
| 使役 `shieki-doushi` | 命子封帥車二百乗以伐京 | 春秋左氏伝 隠公元年 | `saden-shifu` |
| 受身 `ukemi-tokoro` | 先即制人後則為人所制 | 史記 項羽本紀 | `shiki-sakinzureba` |

**抑揚は 1件 → 3件**になり、しかも**「猶」の形と「尚」の形が両方そろった**
（型の名前は「A 猶 B、況 C 乎」なのに、それまでの唯一の実例は「尚」を使う文だった）。
使役・受身はそれぞれ 1件 → 2件。

### 原文の確認（すべて `action=raw` で取得した文字列そのまま）

| 白文 | 原文 |
|---|---|
| 蔓草猶不可除… | `蔓，難圖也。蔓草猶不可除，況君之寵弟乎？！` |
| 布衣之交尚… | `臣以爲布衣之交尚不相欺，況大國乎！` |
| 命子封… | `命子封帥車二百乘以伐京。` |
| 先即制人… | `吾聞先即制人，後則為人所制。` |

- **句読点はすべて `！` または `。`**。前回「？」で落とした詠嘆のような取り違えは無い
- 字体は `爲→為`・`國→国`・`乘→乗` を通行字体に直した（`kyujitai.js` の対応表に載っている）
- `蔓草…` の底本は `？！` の重ね。**反語まじりの詠嘆的な抑揚**だが、
  上に「猶」・下に「況〜乎」がそろうので抑揚として採る

### 訓点は自前で組んだ

- 蔓草猶不可除… … `不レ 可レ 除`（レ点の連鎖）。抑揚そのものには返り点が付かない
- 布衣之交尚… … `不二 … 欺一`。「相」を挟むのでレ点にはできない
- 命子封… … **一二点が2組**（`命二…封一` と `帥二…乗一`）＋ `伐レ 京`。
  2組は入れ子ではなく前後に並ぶだけなので、どちらも一二点でよい
- 先即制人… … `制レ 人`／`為二 人 所一レ 制`。**「一レ」の合字**は既存の
  `宅為人所奪`（`為二 人 所一レ 奪`）と同じ組み方をなぞった

4件とも `lane-verify.js` の二重帳簿（訓点→読み順→書き下し）を通し、
実機 L1 でタップして「○ 全部正しい順に読めました！」まで確認している。

## 残り（第2回以降）

まだ実例が1件のままの型:

| 型 | 名前 | 見通し |
|---|---|---|
| `hitei-zenbu` | 全部否定（副詞＋不） | **短文で成立する例が乏しいという見立て**。要調査 |
| `hitei-hizunba` | 否定条件（非A不B） | 「非…無以…」の形が多く、「不」で受ける形を探す必要がある |
| `gentei-ruika` | 累加（不唯A亦B） | 上下がそろって1文に収まるものを探す |
| `gentei-sugizu` | 限定（不過〜にすぎず） | 短いもの（4〜12字）が欲しい。いまの1件は16字 |
| `eitan-anizuya` | 詠嘆（豈不A哉） | 反語と紛れるので底本の句読が要る |
| `eitan-nanzosore` | 詠嘆（何其A也） | 同上。論語 子罕「何其多能也」は前回「？」で落としている |

熟語返り（連読符）も **4問5トークンのまま**。
**「二字の動詞熟語＋目的語」の形でだけ実文に現れる**（`material-renshokufu.md`）ので、
`大破` 以外の熟語で探す。
