# Gemini 依頼パック: 「日本語での用法」の読み取り結果を、紙面と1行ずつ照合する

## これは何の作業か

添付の PDF（漢和辞典のページ）から、別のチャットで「日本語での用法」札の中身を JSON に書き出した。
ところが抜き取りで確かめると、**紙面に無いことを書いた行があった**
（例: 「丁」の欄に無い「少し・わずか（一丁前）」を書いていた）。

そこで、**JSON の各行が紙面と合っているかを1行ずつ照合してほしい。**
新しく書き出すのではなく、**答え合わせ**が仕事。

---

## やり方

JSON の1行ごとに、`pdf_page` のページを開き、`headword` の項の **青枠の札「日本語での用法」の欄**を読んで、
次の3つを紙面と見比べる。

1. `headword` … 札は本当にこの親字の項に付いているか
2. `jp_readings` と `examples` … **一語ずつ**、欄に印刷されているか
3. `jp_senses` の `gloss` … 欄に書かれている意味の言い換えになっているか。欄に無い意味が混ざっていないか。
   逆に、欄にある意味が大きく抜けていないか

## 絶対の制約

- **辞典の文章を書き写さない。** 直すときも、読み・用例の語・自分のことば 30 字以内の説明だけを使う
- **自分の知識で「正しそう」と判断しない。** 基準は紙面に印刷されているかどうかだけ
- 字がつぶれて読めない、欄が次の段やページへ続いていて追えない、などは `"判断不能"` にして理由を書く

---

## 出してほしいもの（入力の1行につき1オブジェクト・JSON配列で、入力と同じ順に）

| キー | 中身 |
|---|---|
| `pdf_page` / `headword` | 入力の値をそのまま |
| `verdict` | `"一致"` / `"不一致"` / `"判断不能"` |
| `problems` | 不一致の中身の配列（例 `"examples の『一丁前』は欄に無い"`, `"gloss『少し・わずか』は欄に無い"`, `"欄の『書物の紙一枚』が抜けている"`）。一致なら `[]` |
| `fixed` | 不一致のときだけ、**直した後の行**（入力と同じ形: `jp_readings`, `jp_senses`, `kanbun_caution`）。紙面に印刷されている内容だけで作り直す |
| `note` | 判断不能の理由など |

最後に、`一致` `不一致` `判断不能` の件数を1行で書く。
