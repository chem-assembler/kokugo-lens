## 1. 著作権の線引き（化学レンズの設計書 §1 を引き継ぐ）

- **事実は載せてよい。文章・例文の選び方・章立ては写さない。**『漢文道場』『ヤマのヤマ』『例解漢和辞典』は
  裏取りと「何を教えるか」の確認にだけ使う。本文・解説・設問・例文をリポジトリに入れない
- **例文はアプリ自身の問題データ（texts.json・PD の原典から自作した訓読）だけを使う**。参考書の例は
  すべて texts.json の問題 id で引くので、書籍の例文を持ち込む余地がない
- 句法の並び（否定→疑問→反語…）は受験漢文で広く共通する順で、特定の本の章立てではない。
  ただし**節の切り方・見出し・説明の順序は自分で組む**。『漢文道場』の基礎編（10単元）は
  「抜けている論点がないか」の照合表としてだけ使う
- 各ページの前書きに `why`（なぜこの節を立てたか・何を確かめたか）と `source`（裏取りした資料と頁）を書く。
  画面には出さない

## 2. 章立て（案）

「読み方の手順」の順に並べ、句法はその中の一段として置く。

| 章 | 中身 | つながるアプリ |
|---|---|---|
| 序 | 白文 → 返り点 → 書き下し → 句法 → 現代語訳、の手順の全体図 | ハブ |
| 1 語順 | 主語→述語→目的語、**修飾語→被修飾語**（孰与君少長＝君の少長に）、返読文字、目的語の前置（何A之有・唯A是B）。**句読点で句を切り、句の中で語順を見る** | 書き下し練習 K、訓点モード |
| 2 訓点 | 語順に対する訓点。返り点（レ・一二・上中下・甲乙・一レ）、送り仮名、置き字、再読文字。**書き下し文で助動詞にあたる字（不・可・如・若・為〈たり〉など）はひらがなで書く** | 訓点モード L1〜L4・L6、一問一答 kunten/okiji/saidoku |
| 3 否定 | 単純否定・禁止・不可能・部分否定・**二重否定（打ち消しは下にだけかかる）**・否定条件 | kuho: hitei（10型） |
| 4 疑問と反語 | 疑問詞・文末の助字、**疑問か反語かは文意で決める** | kuho: gimon・hango |
| 5 詠嘆 | 嗚呼・哉・豈不A哉・不亦A乎（文意で詠嘆に取る） | kuho: eitan |
| 6 受身と使役 | 見・被・為A所B・使AB・命AB | kuho: ukemi・shieki |
| 7 仮定 | 如・若・使・苟・雖・縦 | kuho: katei |
| 8 比較と選択 | 不如・莫如・於（比較）、**孰与・孰若（熟字訓）**、寧A無B | kuho: hikaku・sentaku |
| 9 限定・抑揚・累加 | 唯・独・耳・而已、況・且、不唯 | kuho: gentei・yokuyo |
| 10 語の使い方一覧 | 一字ごとの読みと使い方の一覧。**日本語の意味の落とし穴はここにまとめる**（下記） | 一問一答 goi、DRAFT_pitfalls.md |
| 11 文章を読む | 明清の筆記・史伝・思想・漢詩のジャンルと読み方、**志怪小説と随筆の違い** | 志望校案内、一問一答 shutten |

レビュアー回答（2026-10-15）で直した点:
- **語順が先、訓点はそれに対するもの**なので、たたき台の1章（訓点）と2章（語順）を入れ替えた
- たたき台の3章「読みを決める語」は独立した章をやめ、**10章「語の使い方一覧」**にまとめた。
  日本語の意味の落とし穴も、章を分けずに各語の項目の中に置く

### 10章「語の使い方一覧」の形

- 見出しは一字（二字の熟語は、その熟語の先頭字の項目の中に置く）。並びは五十音順
- 1項目に置くもの:
  - **読み**と、それぞれの**働き**（品詞・意味）と見分け方
  - **二字で特殊な読みになる熟語**（孰与・所以・是以 など）は、一字の読みと並べて区別を示す
  - **日本語の意味の落とし穴**（日本語だけの意味・読み。漢文には無い）
  - アプリの例（texts.json の問題 id）
- 例: 「乃」＝すなはチ（そこで・やっと）／なんぢ。則・即・輒との読み分け。
  「是」＝こノ／こレ（〜である）／是くのごとし／是に於いて／是とする（正しい）。
  「白」＝まうス（申し上げる）。日本語の「しらける」「シロ（無罪）」は漢文に無い
- 収録する字の候補: 一問一答の頻出語（35項目）＋ DRAFT_pitfalls.md の字＋例解漢和辞典の調査（281件）のうち
  アプリに出る字

『漢文道場』基礎編との照合: 10単元の論点はすべて上の 1〜9 に入る。「基本構文」は 1、
「抑揚・限定・累加」は 9 にまとめた。逆に道場に無い 10（語の使い方一覧）と 11 は、レビュー指摘と
入試データ（docs/exam-kanbun-sources.md）から立てた独自の章。

## 3. 問題とのつなぎ方

- **キーは句法の型 id（kuho.json の types[].id）と一問一答の code**。参考書の節が `codes:` に
  型 id／code を持ち、問題側は自分の id だけを渡す。**着地先は参考書側が決める**（化学レンズと同じ約束）
- 問題 → 参考書: 訓点モードのクリア後の解説に「📖 この句法を読む」。texts.json の `kuho` 配列の
  **先頭の型**の節へ飛ぶ。1問が複数の句法を持つときは全部をチップで並べ、押したものへ飛ぶ
- 参考書 → 問題: 節の終わりに「この節の問題」。その型を持つ問題 id を texts.json から機械で集め、
  `kanbun/index.html?p=<id>` で開く（既存の句法クイズの「収録例」と同じ出口）
- アンカーは `#ref-sec-<anchor>`、帰り道は `?from=reference&page=<id>`（化学レンズに合わせる）
- 検査: **1つの型 id は1つの節にだけ置く**（化学レンズの REF29 相当）。どの節にも置かれていない型を警告

## 4. 化学レンズから流用するもの・作り直すもの

調査（2026-10-14、C:/Antigravity/OrganicChemistryPuzzle）の結論。

- **流用**: 原稿の文法（前書き＋`:::種類` のブロック、本文は1段落1行、記法は `**強調**` だけ）、
  `ORDER.txt`／`TOC.txt`／`PLANNED.txt`、生成器の `--check`（過不足・リンク切れ・生成物の1バイト一致）、
  節ごとの出口と帰り道の帯
- **作り直し**: 化学専用のブロック（反応式・機構表・作図）。漢文には次のブロックを新設する
  - `:::example` … texts.json の問題 id を指すだけ。白文・訓点・書き下し・意味はデータから描く（手で持たない）
  - `:::contrast` … 二つの読みを並べて違いを示す（是れ／是くの、孰与／与…孰、など）
  - `:::mistake` … 化学レンズの `wrong / right / why` をそのまま使う（落とし穴の欄）
- **描画**: 漢文には化学の「資料ペイン」に当たる場所がまだ無い。まずは独立ページ（面A に相当）
  `/kanbun/reference/` を作り、訓点モードの解説からリンクする。横並びの埋め込みは次の段
