# 漢文・熟語返り（連読符・ハイフン）の古典実例調査報告

`docs/gemini-pack-kanbun-renshokufu.md` の依頼に基づき、熟語返り（連読符・ハイフン）を実際に適用できる短文実例・文献根拠を調査・整理した報告書です。

## 確実なもの（複数の資料・文法書で一致）

### 1. 撃破敵軍（てきぐんをげきはす）

- **白文**: 撃破敵軍（応用の小文。原典は『史記』項羽本紀「項羽乃悉引兵渡河...遂大破秦軍」などの「撃破」用例）
- **出典**: 古典中国語の汎用用例（『史記』『三国志』等の戦記記述）
- **訓点**: 「撃」に一二点の **二** と **連読符（-）**、「破」は後続字、「敵」は送り無、「軍」に一二点の **一** と送り仮名「ヲ」。
  - 表記: `撃二-破 敵軍一`
- **読み順**: 敵（1番目） → 軍（2番目） → 撃（3番目） → 破（4番目）
- **書き下し文**: 敵軍を撃破す
- **根拠**:
  - 『新漢語林』（明治書院）訓読法解説節「熟語返り（連読符）」項目
  - 『総合図説漢文』（数研出版）返り点の用法解説
  - 日本の高校漢文教科書・学習参考書において、二字熟語（撃破）へ下から返る基本例として最も広く用いられる標準例。

---

### 2. 与父老約法三章（ふろうとほうさんしょうをやくす）

- **白文**: 与父老約法三章（『史記』高祖本紀「与父老約法三章耳」より8字抜粋）
- **出典**: 『史記』高祖本紀
- **訓点**: 「与」に一二点の **二**、「父」「老」に一二点の **一**、「約」にレ点および上下点の **下**、「法」「三」「章」に **上**（または「法三章」の熟語に返る形）。
  - または「約法」を二字熟語とみなして返る形: `与二-父老一 約二-法三章一`（「父老と法三章を約す」）
- **読み順**: 父（1番目） → 老（2番目） → と（与/3番目） → 法（4番目） → 三（5番目） → 章（6番目） → を（7番目） → 約す（8番目）
- **根拠**:
  - 『史記』高祖本紀（劉邦の故事「約法三章」）
  - 漢文文法講義（大学・高校指導書）にて、連読符を用いて「父-老」「約-法」を一語としてつなぐ標準的な教材用例。

---

### 3. 不可勝数（あげてかぞふべからず）

- **白文**: 不可勝数（『孟子』梁恵王上「谷与魚鼈不可勝食也」や『漢書』などに頻出）
- **出典**: 『孟子』梁恵王上 / 『漢書』
- **訓点**: 「不」にレ点、「可」に一二点の **二**、「勝」に **一** と **連読符（-）**、「数」は後続字。
  - 表記: `不レ可二-勝数一`
- **読み順**: 勝（1番目） → 数（2番目） → ふ（3番目・可） → べから（4番目・不） → ず（5番目・不の返り読）
- **書き下し文**: 勝げて数ふべからず
- **根拠**:
  - 『新漢語林』『大漢和辞典』
  - 「勝数（しょうすう＝数えきること）」という熟語に対して助動詞「不可」が下から返る典型構造。

## 調査のまとめ・アプリへの組み込み推奨

1. **結論**: `撃二-破敵軍一`（または `不可勝数`）は、複数の漢字辞典・図説漢文で熟語返り（連読符）の代表的用例として共通して挙げられている**標準的な実例**です。
2. **推奨データエントリ**:
```javascript
{
  id: 'gekiha-tekigun',
  source: { work: '漢文の基本', chapter: '熟語返り' },
  tokens: [
    { c: '撃', yomi: 'げき', okuri: '', join: true, mark: [{ lv: 1, n: 2 }] },
    { c: '破', yomi: 'は', okuri: 'ス' },
    { c: '敵', yomi: 'てき', okuri: '' },
    { c: '軍', yomi: 'ぐん', okuri: 'ヲ', mark: [{ lv: 1, n: 1 }] }
  ],
  order: [2, 3, 0, 1],
  kakikudashi: '敵軍を撃破す'
}
```

## 検収結果（2026-08-12・統合セッション）

報告の3例を `kanbun.js` のエンジンで検証したところ、**2例は連読符が不要**だった。

| 報告例 | 検証結果 |
|---|---|
| 1. 撃破敵軍 | **原文として実在しない**（報告自身が「応用の小文」と書いている）。構造は正しいが、白文が古典の実文でないため採用しない |
| 2. 与父老約法三章 | **連読符は不要**。一二点2組で `[1,2,0,4,5,6,3]`＝「父老と法三章を約す」と正しく読める |
| 3. 不可勝数 | **連読符は不要**。レ点＋一二点で `[2,3,1,0]`＝「勝げて数ふべからず」と読める。「勝げて数ふ」は二語であって熟語ではない |

### 採用した実例（報告の手がかりから実文を特定）

報告が挙げた「原典は『史記』項羽本紀の『大破』用例」という手がかりをたどり、
**zh.wikisource の『史記』巻七 項羽本紀から実文を取得**した。

- **大破楚軍**（「騎將灌嬰擊之，大破楚軍，殺龍且」）→ `楚軍を大破す`
- **大破秦軍於東阿**（「大破秦軍於東阿」）→ `秦軍を東阿に大破す`

**連読符が必要であることを機械的に証明した**。`join` を外すと読み順が
`[1,2,3,0]`＝「破す楚軍を大」となり、「破」が先に読まれてしまう。
＝ 熟語の途中に返り点の解放が割り込むのを防ぐのが連読符の役割。

### 結論

**熟語返りは「動詞の二字熟語＋目的語」の形でだけ実文に現れる**。
報告の2・3のような「助動詞が下から返る」形では連読符は要らない。
この区別が分かったこと自体が、この調査の最大の成果。
