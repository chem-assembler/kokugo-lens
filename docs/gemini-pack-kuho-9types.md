# Gemini 依頼パック: 実例が1件しかない句法9型＋熟語返りの白文を探す

> 作成 2026-08-13（v47）。前回（4型・`gemini-pack-kuho-4types.md`）の続き。
> **投げる前に `docs/material-kuho-4types.md` と `docs/material-renshokufu.md` を読むこと。**
> どちらも「報告をそのまま採ると事故る」実例集で、この依頼文はその反省を織り込んで書いてある。

## これは何の作業か

漢文学習アプリ **「返り点でみる漢文」**（https://koku.schoollenz.com/kanbun/ ／ 現在667問）の
句法クイズは **43型**を収録している。実例が無い型はもう無いが、
**実例が1件しかない型が9つ**あり、その1件を落とすと練習ができなくなる。
その**白文探し**をお願いしたい。あわせて、返り点の一種である**熟語返り**の実例も探してほしい。

### なぜ困っているか

- 手元の白文台帳（`docs/material-catalog.md` 498行・`docs/material-minqing.md` 61行）は
  **どちらも消化しきった**。残っている行はどれも「入れない理由がある」行なので、
  **新しい白文を集めるところから始まる**
- 句法クイズの出題自体は型データだけで動くので、**実例が1件でも出題はできている**。
  足りないのは「この型を実際の文で練習する」ための橋渡し
- **推測で白文と訓点を作ると、このアプリが守ってきた「推測で埋めない」という原則を破る**

**この作業が Gemini に向いている理由**: 判断より事実収集が主で、
「その句形が実際に使われている短い原文はどれか」を探す調べ物だから。

---

## 絶対の制約

- **市販の教科書・参考書・問題集の本文や解説を転記しない。** 記録するのは
  **白文（漢字列）と、どの資料で確認できるかというポインタ**だけ
  - 古典中国語の原文（白文）自体はパブリックドメインなので問題ない
  - **編者が付けた訓点は編者の著作物になり得る**
- **推測を事実として書かない。** 裏が取れないものは「未確認」と明記して分ける。
  **確実な1件のほうが、あやしい5件より価値がある**
- 現代語訳・書き下し文は不要（アプリ側で自作する）
- **返り点は書かなくてよい。** 前回は報告の訓点欄が4件中3件で誤っていたため、
  こちら側で組み直す運用に変えた。**欲しいのは白文と出典だけ**

### 前回落ちた4件（同じ落とし方をしないために）

| 落とした白文 | 理由 |
|---|---|
| 晋武帝命諸公各作詩 | **原文に無い**（世説新語 言語第二の全文26,025字を検索して不在） |
| 豈不哀哉 | **原文に無い**（史記 伯夷列伝に「豈不」自体が現れない） |
| 子弑父臣弑君有常不赦 | 実在するが**句形が別物**。校訂者が「常」の下に「刑」を補っており、名詞（常刑） |
| 何其多能也 | 実在するが**底本の句読が疑問符**。詠嘆ではなく疑問 |

**4件とも報告は「確度: 確実」と自己申告していた。** そこで今回は次の2点を必須にする。

1. **原文の所在を、全文が読める URL で示す**（維基文庫 zh.wikisource / 中国哲学書電子化計劃 など）。
   「〜に見える」だけの報告は採れない
2. **底本の句読点（。／？／！）をそのまま書き写す**。疑問と詠嘆はここで分かれる

## A. 実例が1件しかない9つの型

**1型につき2〜3件**あると選べて助かる（9型 × 2件 = 18問が目標）。
「いまある1件」と同じ文は要らない。

### A-1. 全部否定（副詞＋不）　`hitei-zenbu`

- 形: `常 不 A` ／ 読み: **つねニAセず**（いつもAしない）
- 目印: 常不・必不・尽不・倶不 のように、**副詞が「不」の上**に来る
- いまある1件: 簡子毎聴朝常不悦（史記 趙世家）
- **紛らわしい相手**: 部分否定 `不 常 A`＝「つねニハAセず」（いつもAするとは限らない）。
  **副詞と「不」の順が逆**。部分否定のほうは実例が足りているので要らない
- 前回「短文で成立する実例が乏しいのでは」という見立てを書いた。**その見立てが正しいかどうかも知りたい**

### A-2. 否定条件（非A不B）　`hitei-hizunba`

- 形: `非 A 不 B` ／ 読み: **AニあらズンバBセず**（Aでなければ、Bしない）
- 目印: 「非」と「不」が**この順で両方**現れ、**前半が後半の条件になっている**
- いまある1件: 非仙者不能道（池北偶談）
- **紛らわしい相手**: ①断定の否定「非A」＝「Aニあらズ」（条件になっていない）
  ②二重否定「非不A」＝強い肯定（「非」と「不」が隣り合う）
  ③仮定「如A則B」。**欲しいのは「非」が条件を作っている形**

### A-3. 命令の動詞による使役　`shieki-doushi`

- 形: `命 A B` ／ 読み: **AニめいジテBセしむ**
- 目印: 命・召・勧・説・教・遣 など、**それ自体が命令や依頼を表す動詞**が使役の意味を作る
- いまある1件: 相如顧召趙御史書（史記 廉頗藺相如列伝）
- **紛らわしい相手**: 「使」「令」を使う基本形（実例は足りている）。
  **欲しいのは「使・令を使わずに、命じる動詞で使役になる」形**

### A-4. 「為 A 所 B」の受身　`ukemi-tokoro`

- 形: `為 A 所 B` ／ 読み: **AノBスルところトなル**
- 目印: **「為」と「所」が両方**現れ、`為＋動作主＋所＋動詞` の順に並ぶ
- いまある1件: 宅為人所奪（池北偶談）
- **紛らわしい相手**: ①助字の受身「見A」「被A」（実例は足りている）
  ②「為」だけの「〜と為る」（受身ではない）。**「所」が無い形は採れない**

### A-5. 累加（不唯 A 亦 B）　`gentei-ruika`

- 形: `不唯 A 亦 B` ／ 読み: **たダニAノみナラず、まタB**（AだけでなくBまで）
- 目印: 不唯・非唯・不独・非独・豈唯・非徒・不徒・不惟・非惟 が**上**にあり、
  **下に「亦」「又」「而」などで受ける部分がある**
- いまある1件: 非徒無益而又害之（孟子）
- **紛らわしい相手**: ただの限定「唯A耳」（下に受けが無い）。
  **上下がそろって初めて累加**なので、**下の受けまで含めて1文に収まること**が条件

### A-6. 限定（不過 〜ニすギず）　`gentei-sugizu`

- 形: `不過 A` ／ 読み: **Aスルニすギず**（Aするだけのことだ）
- 目印: 不過・不外
- いまある1件: 不過以取科第也而以身殉之不亦惑哉（五雑組・**16字と長い**）
- **短いものが特に欲しい**（4〜12字）。「過ぎない」と訳せることが条件で、
  「過ちを犯さない」の意味の「不過」は別物

### A-7. 抑揚（A 猶 B、況 C 乎）　`yokuyo-nao`

- 形: `A 猶 B、況 C 乎` ／ 読み: **AスラなホB、いはンヤCヲや**
- 目印: **「猶」または「尚」が上**にあり、**下に「況」＋文末の「乎／哉／也」**がある
- いまある1件: 且庸人尚羞之況於将相乎（史記）
- **紛らわしい相手**: 同じ抑揚でも「A 且 B、況 C 乎」（「且」を使う形）は別の型として
  実例を持っている。**欲しいのは「猶」「尚」を使う形**
- 上下がそろって1文（20字以内）に収まることが条件。**「況」だけの文は採れない**

### A-8. 詠嘆（豈不 A 哉）　`eitan-anizuya`

- 形: `豈不 A 哉` ／ 読み: **あニAセずや**（なんとAではないか）
- 目印: 「豈不」が並び、文末が「哉／乎／也」
- いまある1件: 豈不痛哉（王羲之 蘭亭集序）
- **紛らわしい相手**: 反語「豈〜ンや」。反語は「どうしてAだろうか、いやAでない」と**打ち消す**が、
  詠嘆は**感嘆**で意味は肯定になる。**「豈」と「不」が隣り合っていること**が見分けの第一歩
- **底本の句読点を必ず書くこと**（！なら詠嘆、？なら反語の可能性が高い）

### A-9. 詠嘆（何 其 A 也）　`eitan-nanzosore`

- 形: `何 其 A 也` ／ 読み: **なんゾそレAスルや**（なんとAなことよ）
- 目印: 「何其」が並び、文末が「也」または「哉」
- いまある1件: 何其衰也（欧陽脩 五代史伶官伝序・底本は「！」）
- **紛らわしい相手**: 理由をたずねる疑問の「何ゾ」。**答えを求めていない感嘆のほう**が欲しい
- 前回、論語 子罕「何其多能也」を候補に挙げてもらったが、
  **底本の句読が「？」だったので落とした**。同じものを再提出しないこと

## B. 熟語返り（連読符）の実例

いまデータに **4問5トークンしかない**。回帰テストには入っているのに実例が薄い、という
不均衡がずっと残っている。**画面に描く仕組みは 2026-08-13 に入れた**ので、
実例が増えればそのまま学習に使える状態になっている。

### 熟語返りとは（前回の調査で分かった定義）

**二字で一語の動詞に、下から返って読むとき**、返り点は**先頭の字にだけ**付け、
二字をハイフン（縦書きでは縦棒）でつないで続けて読む。つながないと二字目が先に読まれてしまう。

- いまある実例: **大破楚軍**（楚軍を大破す）／**大破秦軍於東阿**（秦軍を東阿に大破す）
  ＝ どちらも `史記 項羽本紀`。ほかに `更易`（五雑組）・`慎重`（五雑組）・`髪指`（分甘余話）

### 前回の依頼で3例中2例が落ちた理由（**ここが今回のいちばん大事な条件**）

| 報告例 | なぜ落ちたか |
|---|---|
| 撃破敵軍 | **原文として実在しない**（報告自身が「応用の小文」と書いていた） |
| 与父老約法三章 | **連読符が要らない**。一二点2組で正しく読める |
| 不可勝数 | **連読符が要らない**。「勝げて数ふ」は二語であって熟語ではない |

→ **結論として分かったこと: 熟語返りは「二字の動詞熟語 ＋ 目的語」の形でだけ実文に現れる。**
「不可」「未嘗」のような**助動詞が下から返る形では連読符は要らない**。

### 今回ほしいもの

**`[二字の動詞熟語] + [目的語]` の形で、実際の古典に出てくる短文**（4〜12字）。

- 二字熟語の例: 大破・大敗・撃破・追撃・厚遇・優待・深入・力戦・痛飲・大赦・寵愛・敬慕 など
  （**これらは「こういう形」の例示であって、この語で探せという指定ではない**）
- 条件: **二字目に返り点が付いてしまうと読み順が壊れる**こと。
  言いかえると「二字目だけを先に読むと意味が通らなくなる」こと
- **`大破` はもう2件あるので、別の熟語**でほしい
- 3〜5件あると助かる

## 必須の条件（A・B 共通）

1. **白文がパブリックドメインの古典であること**。中国の古典でも日本漢文でもよい
2. **4〜20字で意味が完結する短い文**（アプリは1問＝1文。20字を超えると使えない）
3. **その句形が実際に使われている形であること**（上の「紛らわしい相手」と取り違えないこと）
4. **全文が読める URL を示すこと**（維基文庫 / 中国哲学書電子化計劃 など）
5. **底本の句読点をそのまま書き写すこと**

## あると嬉しい条件

- **共通テストや二次で出る作品から取れること**。調査したところ、共通テストの最頻ジャンルは
  **明清の筆記（随筆）26件**、次いで詩と詩話18件で、史伝は6件しかない。
  「受験漢文＝唐宋の史伝」は実態と違うので、**明清の筆記や詩話は特に歓迎**
- 有名で、生徒が「聞いたことがある」文であること
- **すでに収録済みの作品から取れると、出典の説明を使い回せて助かる**（67作品・多い順）:

## 報告の形

型ごとに、見つかった候補を次の形で書いてほしい。

```
## 型: A-1 全部否定（常 不 A）

### 候補1
- 白文: （漢字だけ。底本の句読点はそのまま入れる）
- 字数: （句読点を除いた漢字の数）
- 出典: 作品名・篇名（できるだけ細かく）
- 原文の所在: 全文が読める URL（維基文庫 / 中国哲学書電子化計劃 など）
- 前後の文脈: 前後1文ずつ。句形の判断はここで決まる
- 底本の句読点: 文末が 。 か ？ か ！ か
- 校訂者の補いの有無: 注で字が補われていないか（前回はこれで1件落ちた）
- この型だと言える理由: 「紛らわしい相手」でない根拠
- 確度: 確実 / たぶん / 未確認
```

**返り点と書き下しは書かなくてよい**（こちらで組んでエンジンに通す）。

### 見つからなかった場合

**「見つからなかった」も価値のある報告**なので、そう書いてほしい。
そのとき、**どこを探したか**（どのサイト、どの作品、どんな検索語）を残してもらえると、
次に探すときに同じ場所を掘らずに済む。

## 参考: このアプリが白文をどう扱うか

- 版本の異同は**日本の教科書の通行形**を採る（底本の形は注記に残す）
- 字体差は通行字体に統一する（爲→為・將→将・學→学など）
- **読みが変わる別字（亡＝無「なし」、女＝汝「なんぢ」）は原文のまま残す**。読めないこと自体が学習内容
- 出典の帰属が疑わしいものは「（伝）」と表記して注記で説明する

## 受け取ったあとの手順（アプリ側の作業。依頼先には不要）

1. 報告を `scratch/gemini-kuho-9types.json` などに置く（**`docs/` には置かない**）
2. **字数を機械で数え直す**（前回3件のずれが出た）
3. **原文を維基文庫で全文検索**し、報告の白文がその通りに存在するか確かめる
4. **句読点と注釈を見る**（疑問／詠嘆の別・校訂者の補い）
5. 訓点は `gemini-intake.js` に組ませるか手で組み、`lane-verify.js` を通す
6. `lane-merge.js --write` → `link-verify.js --write` → 実機 L1 で完答 → 版バンプ → コミット
