## 前提: いまは自力で探せる範囲は探しきっている

このアプリ側では、維基文庫の生テキストを直接読んで集める方法を確立した。

```
https://zh.wikisource.org/w/index.php?title=<頁名>&action=raw          … 原文をそのまま取る
https://zh.wikisource.org/w/api.php?action=query&list=search
  &srsearch=insource:"<文字列>" prefix:史記/&srlimit=20&format=json     … 収録済みの作品に絞って探す
```

これで**9型のうち8型は埋まり、熟語返りも4→6問になった**。
**残っているのは、この方法で探しても出てこなかった2つ**なので、
**広く当たること**（＝手数）が要る仕事だと考えている。そこをお願いしたい。

## 依頼A: 熟語返り（連読符）が必要な短文を探す

### 熟語返りとは（前回の調査で分かった定義）

**二字で一語の動詞に、下から返って読むとき**、返り点は**先頭の字にだけ**付け、
二字をつないで続けて読む。つながないと二字目が先に読まれてしまう。

いま収録しているのは6問7トークンだけ:

| 白文 | 熟語 | 出典 |
|---|---|---|
| 大破楚軍 | 大破 | 史記 項羽本紀 |
| 大破秦軍於東阿 | 大破 | 史記 項羽本紀 |
| 大赦天下 | 大赦 | 史記 高祖本紀 |
| 厚遇戦士 | 厚遇 | 史記 廉頗藺相如列伝（李牧） |
| 与其更易於後孰若慎重於初乎 | 更易・慎重 | 五雑組 |
| 毎観唐詩至此未嘗不髪指也 | 髪指 | 分甘余話 |

### いちばん大事な条件（前回3件中2件はここで落ちた）

**`[二字の動詞熟語] + [目的語]` の形であること。**

| 前回の報告例 | なぜ落ちたか |
|---|---|
| 撃破敵軍 | **原文として実在しない**（報告自身が「応用の小文」と書いていた） |
| 与父老約法三章 | **連読符が要らない**。一二点2組で正しく読める |
| 不可勝数 | **連読符が要らない**。「勝げて数ふ」は二語であって熟語ではない |

→ **「不可」「未嘗」のような助動詞が下から返る形では連読符は要らない。**
判定は「**二字目だけを先に読むと意味が通らなくなるか**」。通ってしまうなら不要。

### 探してほしいもの

- **4〜12字で意味が完結する短文**を **3〜5件**
- **`大破`・`大赦`・`厚遇` 以外の熟語**で
- 目的語を取る二字動詞の例（**これは形の例示で、この語で探せという指定ではない**）:
  大敗・撃破・追撃・掩撃・深入・力戦・痛飲・厚賜・厚葬・優待・寵愛・敬慕・重賞・大宴
- **`大敗` は史記で当たったが `大破` の用例に埋もれて切り出せなかった**。ここを掘ってもらえると助かる

### 参考: すでに当たって空振りだった探し方

- `insource:"大敗" prefix:史記/` … 23巻にヒットするが、原文を読むと自動詞の
  「〜大敗す（負けた）」が多く、目的語を取る形が切り出せなかった
- `insource:"厚葬" prefix:史記/` … 6巻。中身は未確認

## 依頼B: 詠嘆「何其 A 也」で、底本の句読が「！」の用例を探す

### 何が問題か

- 型: `何 其 A 也` ／ 読み: **なんゾそレAスルや**（なんとAなことよ）
- **紛らわしい相手**: 理由をたずねる疑問の「何ゾ」（答えを求めている）
- このアプリは**底本の句読点で疑問と詠嘆を分ける**規律で運用している。
  ところが**「！」で終わる用例が1つしか見つからない**

| 出典 | 用例 | 底本の句読 |
|---|---|---|
| 五代史伶官伝序（欧陽脩） | 何其衰也 | **！** ＝ いま収録している唯一の実例 |
| 史記 卷047 孔子世家 | 何其正也 ／ 汝來何其晚也 | ？ ／ ？ |
| 莊子 齊物論 | 何其无特操與 | ？（しかも文末が「與」） |
| 孟子 盡心上 | 此非吾君也，何其聲之似我君也 | ？ |
| 孟子 盡心下 | 而何其血之流杵也 | ？ |
| 論語 子罕 | 何其多能也 | ？（2026-08-12 に落としたぶん） |

史記は全巻のうち「何其」を含むのが14巻しかなく、読んだものはすべて疑問だった。

### 探してほしいもの

**「何其 A 也（哉）」で、底本の句読が「！」になっている用例**を、**1〜2件でよい**ので。

- 中国の古典でも日本漢文でもよい
- 4〜15字で意味が完結すること
- **どの底本で「！」なのかを必ず示す**（維基文庫なら該当頁の URL）

### 「見つからない」も立派な報告

**探した範囲を書いてもらえれば、それ自体が結論になる。**
こちらは「用例が無い」という前提で1件のまま据え置く判断をすでにしてあるので、
**それを裏づける報告でも十分に価値がある**（どこを探したかが残れば、次に掘り直さずに済む）。

そのとき、次の点についての見立ても知りたい:

> 「何其A也」は**中国語としては形の上で疑問文**なので、近代の校訂者は「？」を打つが、
> **日本の訓読では詠嘆として教える**。この食い違いは一般的なものか？
> それとも「！」で校訂されている版が実際にあるのか？

## 報告の形

```
## 依頼A / 候補1
- 白文: （漢字だけ。底本の句読点はそのまま入れる）
- 字数: （句読点を除いた漢字の数）
- 熟語: （二字の動詞。例「大破」）
- 目的語: （その下に来る語）
- 出典: 作品名・篇名（できるだけ細かく）
- 原文の所在: 全文が読める URL
- 前後の文脈: 前後1文ずつ
- 二字目だけ先に読むとどうなるか: （連読符が要る根拠。例「破す楚軍を大」になり通らない）
- 確度: 確実 / たぶん / 未確認

## 依頼B / 候補1
- 白文:
- 字数:
- 出典:
- 原文の所在: 全文が読める URL
- 底本の句読点: 「！」であることが分かる形で
- 前後の文脈: 前後1文ずつ（詠嘆か疑問かはここで決まる）
- 確度: 確実 / たぶん / 未確認
```

## 受け取ったあとの手順（アプリ側の作業。依頼先には不要）

1. 報告を `scratch/gemini-nokori.json` などに置く（**`docs/` には置かない**）
2. 字数を機械で数え直す／原文を `action=raw` で全文検索して実在を確かめる
3. 依頼Aは `join` を外して読み順が壊れることをエンジンで確かめる（＝連読符が要る証明）
4. 依頼Bは句読点と前後の文脈を見て、疑問／詠嘆を自分で決める
5. 訓点は自前で組み、`lane-verify.js` → `lane-merge.js --write` → `link-verify.js --write` → 実機 L1
