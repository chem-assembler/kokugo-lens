# 句法4型の白文 — 依頼と検収の記録（2026-08-12・v22）

`docs/gemini-pack-kuho-4types.md` で依頼した「実例を持たない4型のための白文探し」の
報告（8候補）を検収した記録。**8件中4件を採用し、4件を落とした**。

**採用の判断はすべて原文に当たって行った**。報告はすべて「確度: 確実」と自己申告して
いたが、そのうち**2件は原文に存在せず、1件は句形が別物、3件は字数が違った**。
熟語返りの依頼（`material-renshokufu.md`）でも3例中2例を落としており、
**自己申告の確度をそのまま信じない**という運用はここでも正しかった。

### 訓点は報告の記述を使わなかった

報告の「返り点の付き方」の欄は**4件中3件で誤っていた**ため、採用分の訓点は自前で組み、
`readOrder` と `toKakikudashi` に通して読み順と書き下しが一致することを確かめてから収録した。

- 簡子毎聴朝常不悦 … 報告は「朝→聴のレ点」「悦→不のレ点」の2つだけ。
  **「毎」へ返る一二点が抜けている**（正: 毎［二］聴［一レ］朝 … 不［レ］悦）
- 相如顧召趙御史書 … 報告は「趙御史に二点、書に一点」。**逆**（正: 召［二］… 史［一］）
- 豈不痛哉 … 報告は「不→豈へ一二点」も要るとするが、**「豈」は最初に読むので返らない**
  （正: 不［レ］痛 のみ）

### 字体

- 相如顧召趙御史書 … 底本（維基文庫）は「趙**禦**史」。字体差なので通行の「御」に統一
  （README の異体字の方針 (a)）

## 不採用（4件）

| 白文 | 報告の出典 | 落とした理由 |
|---|---|---|
| 子弑父臣弑君有常不赦 | 呂氏春秋 / 戦国策 魏策 | **句形が別物**。原文（戦国策 魏策四・縮高の故事）は実在したが、
底本の注が「常」の下に「刑」を補っており、ここの「常」は副詞の「つねに」ではなく**名詞（常刑）**。
「常刑有りて赦さず」であって全部否定ではない。字数も報告の9字に対し実際は10字。
出典が2つ併記されていたこと自体が不確かさの表れだった |
| 晋武帝命諸公各作詩 | 世説新語 言語第二 | **原文に無い**。言語第二の全文（26,025字）を検索したが該当なし。字数も9字（報告は8字） |
| 豈不哀哉 | 史記 伯夷列伝 | **原文に無い**。伯夷列伝の全文を検索したが「豈不」自体が現れない |
| 何其多能也 | 論語 子罕 | **実在するが疑問**。底本の句読は「夫子聖者與？何其多能也**？**」で疑問符。
詠嘆の実例としては採れない。依頼時にこの点を確かめてほしいと書いたが、報告は触れずに「確実」としていた。
なお採用した「何其衰也」は底本が「**！**」で、こちらが詠嘆 |

## この検収でやったこと（次回の手順）

1. **字数を機械で数え直す**（3件のずれが出た）
2. **原文を維基文庫で全文検索**し、報告の白文がその通りに存在するか確かめる（2件が不在）
3. **句読点を見る**。疑問符か感嘆符かで、疑問と詠嘆が分かれる（1件はこれで落とした）
4. **注釈を読む**。校訂者が字を補っていれば、その句形の解釈が変わりうる（1件はこれで落とした）
5. 訓点は自前で組み、`readOrder` / `toKakikudashi` に通してから収録する
