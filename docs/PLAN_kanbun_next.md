## 1. `H-04f` を収録する（1問・半日）→ **済（2026-08-13・v44）**

**台帳に残った4行のうち、唯一「入れられる」もの。** ほかの3行は入れない理由がある
（`K-01b` は `mujun-2` と重なる／`S-36` は前半後半を別々に収録済み／
`S-65e` は「〜者は」で切れる従属節）。

- 白文: `彊秦之所以不敢加兵於趙者、徒以吾兩人在也`（19字。長いので**後半で切る**）
- 収録した形: `徒以吾両人在也` →「徒だ吾が両人の在るを以てなり」（id `funkei-tada`）
- 訓点は `徒ダ 以テ二 吾ガ 両 人ノ 在ルヲ一 也`。限定の副詞は先に読むので「徒」に返り点は付かない
- 型 `gentei-tada` に結んだ。結ぶために型データへ標識「徒」と読み「徒だ」を足している
  （`markers` に「徒」が無く `link-verify.js` の規則10で弾かれたため）

### この節の当初の目当て「熟語返り」は達成できていない

もとの計画は「H-04f を**熟語返りで**組む」だったが、**連読符は入っていない**。理由:

- 連読符の当てどころだった **「所以」は切り落とした前半にしかない**。後半 `徒以吾両人在也` に
  二字で一語として返る箇所はひとつも無い
- そもそも**このリポジトリは「所以」を連読符で組んでいない**。既存5件
  （`kanpeki-yuen` / `suishi-koryu` / `suishi-keitai` / `shisetsu-yuen` / `kiro-kaeru`）は
  すべて **所=二・以=三 の二・三点**で組んである。新規だけ連読符にすると流儀が割れる

→ **熟語返りが5トークンしかない、という不整合は手つかずで残っている。**
素材から集め直す仕事なので、実質 §2 と同じ性質。§2 に混ぜて依頼パックを作るのが早い。

既存の熟語返りの実例（形をまねる）:

| id | 白文 | 書き下し |
|---|---|---|
| `shiki-taiha-sogun` | 大破楚軍 | 楚軍を大破す |
| `shiki-taiha-shingun` | 大破秦軍於東阿 | 秦軍を東阿に大破す |

> **`shiki-taiha-shingun` の返り点は誤りだった → 直した（v45）。** 大=下（lv2 n3）・阿=上（lv2 n1）で、
> **内側に一二点がひとつも無いのに上下点を使っていた**。上下点は一二点をまたぐときの印なので、
> 阿=一・大=二 が定石。note の「上下点と置き字が同居する上級の形」も書き換え、難度は 7.8 → 5.8 になった。
> 読み順は上下点でも正しく出るため**二重帳簿は素通りしていた**。全667問でこの1件だけ。
> 同じ抜けを塞ぐ検査を `tests.js`（収録済み全問）と `tools/lane-verify.js`（収録前）に入れてある。

> **`join`（連読符）は画面に描かれていなかった → 描いた（v47）。** それまでは「大破秦軍」が
> `大二 破ス 秦 軍ヲ一` としか見えず、なぜ大→破と続けて読むのかが画面から読み取れなかった。
> いまは字と字の境をまたぐ朱の縦棒（`.joiner`）が出て、モードの操作説明にも一文が足される。
> **描けるのは相手が隣の字のときだけ**なので、その前提を `tests.js` と `lane-verify.js` で固定してある。
> ＝ 熟語返りの実例を増やせば、増やしたぶんがそのまま画面に出る状態になった。

手順は `lane-verify.js` → `lane-merge.js` → 実機 L1 で完答、といつもどおり。

## 踏んではいけない穴（すべて 2026-08-13 に実際に踏んだ）

1. **返りを全部収録し終えるまで、依頼パックを作り直さない。**
   `gemini-pack.js` はそのときの未収録行を数え直して束に割るので、
   途中で作り直すと2束目以降がそっくり入れ替わり、**どの束にも入らない行が出る**。
   S系36行が宙に浮き、消化しきったつもりで終わるところだった
2. **字体の対応表（台帳 §8.1）の注意書きをコードフェンスの中に書かない。**
   表を読む正規表現が矢印の前後1字を拾うので、「鞦韆→鞦韆(そのまま)」という
   注記から**「韆→鞦」という対応を作ってしまい**、白文が「鞦鞦」になった
3. **機械検査を通ることと、教えとして正しいことは別。**
   1束目36件は機械を 36/36 通ったが、定訓と照らすと30箇所直した。
   「獣すら相食む」（正しくは「獣の相食むすら」）のように**意味が変わる誤り**も混じる
4. **読み仮名（yomi）は書き下しに出ないので、送り仮名の割り直しでは直らない。**
   `yomi-check.js` が最後の砦。収録後に落ちたら直す
5. **返り点は `gemini-intake.js` が組む。外に組ませない。**
   階層の割り当てに2度不備が出ており（待っている字が別の組の「一」で巻き添え解放される／
   起点が待機中の字を兼ねる）、どちらもエンジンの規則を知らないと踏む
6. **`note` の `**` はもう画面に出ない（2026-08-13・v46 で対処済み）。**
   それまでは `innerHTML` に素の文字列を差し込んでいたので、55問でアスタリスクが
   そのまま表示されていた。いまは `Kanbun.noteHtml()` が `<strong>` に変える。
   **強調は `**…**` で閉じること**（閉じ忘れは `lane-verify.js` が止める）。
   なお **note に内部の問題 id を書かない**（生徒に `funkei-ryouko` は意味を持たない）。
