# 国語レンズ（KokugoLenz）

SchoolLenz の第3の教科サブブランド。
**公開中: https://koku.schoollenz.com/** （2026-08-11 公開）
リポジトリ: `chem-assembler/kokugo-lens` ／ GitHub Pages（main / ルート）／ HTTPS 強制済み

## 構成

- ルート `index.html` … 国語レンズのハブ（アプリ一覧。自己完結・外部アセットなし）
- **`/kanbun/`** … 返り点でみる漢文（第1弾アプリ）
- **`/qa/`** … 一問一答（漢文）。**chem の `/qa/` エンジンをそのまま流用**し、
  台帳（`questions.json`）だけ漢文用に差し替えた。`node qa/check.js` が台帳を検査する
- `DESIGN_kanbun.md` … 設計書（決定事項・データモデル・アルゴリズム・実装順序の正）
- `PUBLISH_CHECKLIST.md` … 公開手順（GitHub Pages ＋ koku.schoollenz.com）
- `docs/` … 題材選定の資料（下記）

**この2つの使い方**: `exam-kanbun-sources.md` の優先題材リストで「何を入れるか」を決め、
`material-catalog.md` の行IDで「その白文を引く」。訓点と書き下しは自作し、
`tests.js` の二重帳簿検査（訓点→読み順→書き下し）を必ず通す。

起動: リポジトリルートでローカルサーバーを立てる（例: `python -m http.server 8138` →
`http://localhost:8138/kanbun/`）。file:// 直開きは texts.json の fetch が失敗する。

## 白文を `texts.json` に入れるときの仕様（2026-08-05 確定）

台帳（`docs/material-catalog.md` §8）から白文を投入するときの判断はここで固定する。
毎回迷わないための仕様であり、**個別の気分で覆さない**。

### 版本の異同 → **日本の教科書通行形を正とする**

底本（Wikisource は多くが『全唐詩』系）と教科書の通行形がずれる場合、**通行形を採る**。

| 作品 | 底本 | 採用する形 |
|---|---|---|
| 静夜思 | 牀前**看**月光／望**山**月 | 牀前**明**月光／望**明**月 |
| 黄鶴楼送孟浩然之広陵 | 碧**山**尽 | 碧**空**尽 |
| 早発白帝城 | 啼不**尽** | 啼不**住** |
| 前赤壁賦 | 蘇軾自筆真跡 | 通行本 |

理由: このアプリの目的は本文批評ではなく受験・学習。生徒の教科書に「明月光」とある横で
「看月光」を出しても、学習上の利益ゼロで混乱だけが生まれる。決定的なのは
**これらの異同が読み順（＝このアプリが扱う対象）を一切変えない**こと。
ただし「知らずに通行形にした」状態にしないため、**底本の形は `note` に残す**。

### 異体字 → **2つに分けて扱う（一律にしない）**

**(a) 単なる字体差は通行字体に統一する**

`楯→盾` `兔→兎` `靑→青` `无→無` `步→歩` `蜚→飛` `凋→彫` `巵→卮` `蹞→跬`。
読みも意味も変わらないので統一しない理由がない（既存の `mujun-1` が「盾」なので、
統一しないとデータ内で不整合になる）。旧字体→新字体の一括対応表は台帳 §8.1。

**(b) 読みが変わる別字は原文のまま残し、教材にする**

| 字 | 読み | 出てくる場面 |
|---|---|---|
| **亡** | ＝「無」。**「なし」と読む**（「ほろぶ」ではない） | 杞憂「亡處亡氣」 |
| **女** | ＝「汝」。**「なんぢ」と読む** | 臥薪嘗胆「女忘會稽之恥邪」 |

「原文のままだと初学者が読めない」が、**読めないこと自体が学習内容**。
台帳 §8.5「引っかけになる行」にも挙がっており、入試で実際に差がつく。
**読み仮名トグルと `note` で教える**方針にし、置換して潰さない。

### 出典の帰属が疑わしいもの → **「（伝）」と表記し `note` で説明する**

消さずに残し、教科書の記述をそのまま事実と思わせない。
実例: `shonen-1` / `shonen-2`（偶成）は一次典拠がなく朱熹への仮託と考えられるため
`chapter` を「朱熹（伝）」とし、`note` に経緯を書いた。
化学レンズの `qa/KNOWLEDGE_CAVEATS.md`（教科書の単純化を事実と思い込むと事故る）と同じ思想。

## 重要ルール（化学レンズと同じ規約）

- 全ファイル **UTF-8（BOMなし）**。コミット前に Shift_JIS 誤解釈由来の化け文字がないか確認
  （検査パターンの文字自体をファイルに書くと自己検出するので、パターンは chem の CLAUDE.md を参照）
- **このリポジトリでは化け検査が誤検出する**。検査パターンに使う文字はどれも実在の漢字で、
  漢文の作品名・人名に正当に現れる（実例: `彪邨文集`＝岡直養の日本漢文集。「邨」は「村」の異体字）。
  **一致したら機械的に直さず、前後を読んで実在の漢字かどうかを必ず judge すること**
- 採点は**訓点の表記ではなく読み順**で行う（レ点でも一二点でも、読み順が合えば正解＝ variant）
- バージョン `vNN` はコミットごとに `kanbun/index.html`・`kanbun/test.html` のキャッシュバスター＋表示を同時更新
- 1修正=1コミット。ブラウザで実機検証し、検証内容をコミットメッセージに記録
- 訓読には流派差があり正解が一意でない（設計書 §4.3）。失敗例を見つけたらテストを足して直す＝**テストが仕様の正**
