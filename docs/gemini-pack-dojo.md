# Gemini 依頼パック: 漢文の問題集の「骨組み」を書き出す（1回で全体）

## これは何の作業か

漢文学習アプリ **「返り点でみる漢文」**（https://koku.schoollenz.com/kanbun/）に、
**演習のすぐ横に教科書がある「アプリ埋め込み型の参考書」**を作りたい。

その目次と順序の手本として、添付の問題集（PDF・218ページ）の**骨組み**を知りたい。
欲しいのは本文や解説の中身ではなく、**「どの単元で、何の論点を、どんな順に、どんな形式で問うているか」**。
目次を見ると、第一部「基礎編」（句法の10単元）と第二部「練成編」（長文読解）に分かれている。

**この作業が Gemini に向いている理由**: 判断より読み取りと整理が主だから。

---

## 絶対の制約

- **本の文章を書き写さない。** これは市販の問題集（著作物）。
  - 拾ってよいのは: 単元名・見出し・**句形の型**（「不可不A」「A孰与B」のような記号的な形）・
    **出典の書名と篇名**・設問の**形式**（「書き下しせよ」「返り点を付けよ」など）・ページ番号
  - 論点の説明は、**本の言い回しを使わず自分のことばで 40 字以内**にまとめる
  - **白文・書き下し文・現代語訳・解説文・設問文そのものは出さない**
- **推測を事実として書かない。** 読み取れない・判断がつかない所は `"confidence": "低"` と `note` に理由
- ページは**PDF のページ番号**で書く（本に印刷されたノンブルと違う場合は両方書く）

---

## 出してほしいもの

### (1) 全体のまとめ（Markdown・短く）

- 本の構成（部・単元の数、1単元が何ページで、どんな部品から成るか ＝ 例「要点の表 → 例題 → 練習問題」）
- **この PDF に解説（答えの理由の説明）がどの程度含まれているか**。
  解答・解説が別冊で、この PDF に無いならそう書く
- 単元の並べ方の方針として読み取れること（易→難、句法の依存関係など）

### (2) 単元ごとの JSON 配列

| キー | 中身 |
|---|---|
| `part` | `"基礎編"` / `"練成編"` |
| `unit` | 単元番号（目次の番号） |
| `title` | 単元名 |
| `pdf_pages` | `[開始, 終了]` |
| `points` | この単元で教えている論点の配列。各要素は自分のことば 40 字以内 |
| `patterns` | 扱っている**句形の型**の配列（例 `"不可不A"`, `"A孰与B"`, `"使AB"`）。基礎編のみ。無ければ `[]` |
| `question_types` | 設問の形式と、その数のおおよそ（例 `{"形式": "返り点を付けよ", "数": 4}`） |
| `sources` | 本文・例文の**出典**の配列（例 `{"書名": "史記", "篇名": "仲尼弟子列伝"}`）。分かる範囲で |
| `confidence` | `"高"` / `"中"` / `"低"` |
| `note` | 気づいたこと。とくに「この単元の並べ方・見せ方で工夫している点」があれば自分のことばで |

### 出力例（形だけ。中身は架空）

```json
[
  {"part": "基礎編", "unit": 3, "title": "再読文字", "pdf_pages": [14, 15],
   "points": ["一字を二度読む字があり、二度目は返り点で戻って読む", "二度目の読みは助動詞として送り仮名に回す"],
   "patterns": ["未A", "将A", "当A", "宜A", "須A", "猶A", "盍A"],
   "question_types": [{"形式": "書き下しせよ", "数": 5}, {"形式": "返り点を付けよ", "数": 3}],
   "sources": [{"書名": "論語", "篇名": "学而"}],
   "confidence": "高"}
]
```
