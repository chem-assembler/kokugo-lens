# V-K1 漢文は上から順に読まない（百聞は一見に如かず）

**国語レンズの1本目。** 台本 `kanbun/demos.json` の `kaeriten-hyakubun`、訓点モード L1。

## 1. なぜこの題材か

- **読み順が 百→聞→一→見→如→不 と最後に2つ戻る。** 読み順バッジが飛んで付き、
  左に書き下しが伸びる画が、**「漢文は上から順に読まない」という一点だけ**を
  説明ぬきで見せる
- **誰でも知っている慣用句**なので、冒頭でフックの説明が要らない（短尺は最初の1秒が勝負）
- **操作はタップだけ**＝失敗要素がほぼ無い。実収録の1本目に向く

### 3-1. ナレーションに画を合わせた（v56）

**音を先に作り、画をそれに合わせる。** 逆にすると必ず溢れる。
各ステップは `narration/V-K1.json` の1行と1対1にしてあり、
`hold` は「その行の秒数 ＋ 行間の無音 0.6秒 − 操作の実測コスト」で決めた。
操作の実測コストは **1タップあたり pause + 390ms**（v54 の events.json から算出）。

| 行 | 音 | 画面で起きること | ステップの目標 | 実測 |
|---|---|---|---|---|
| 01-hook | 3.8s | 静止（フック） | 4.40 | 4.40 |
| 02-top | 3.3s | 2回タップ | 3.90 | 3.91 |
| 03-kaeri | 5.7s | 静止（返り点の説明） | 6.30 | 6.31 |
| 04-read | 6.4s | 4回タップ＋書き下しが伸びる | 7.00 | 7.02 |
| 05-ed | 4.4s | 静止（結び） | — | 最終は音より長く出すのが正しい |

> **最初の原稿は画と逆立ちしていた。** 03-kaeri が 7.0秒（静止画）で、
> 04-read が 4.0秒（4回タップ＝実測4.4秒）。
> **いちばん喋る行が静止画で、いちばん動く行が短い**という状態だった。
> **`hold` をいじる前に原稿を組み替える**のが正しい
> （「下から戻れ、という合図」を 03 から 04 へ移した）。

## 4. 踏んだ穴（すべて実収録のコマで見つけた。読んでいるだけでは出ない）

1. **冒頭に別の問題が映る。** `applyState`（頭出し）が `delay` の**後**だったので、
   収録開始から2.2秒、既定で開く問題（衆狙皆怒・荘子）がそのまま映っていた。
   → `applyState` を delay の前へ（rec.js・v55）
2. **紙の左9割が白いまま。** 縦書きは右端から始まるのに `#stage` が横いっぱいに広がる。
   → `.rec-short #stage` に `justify-content` / `align-items: center`（v54）
3. **書き下し列の案内文が主役を食う。** ラベルと「（読む順に字をタップすると…）」が
   縦書きで長く伸び、見せたい書き下しと張り合っていた。**字を大きくして初めて目立った**
   → `game.js` が `.placeholder` を付け、CSS が落とす（v54）
4. **演技が始まるまで、文字の無い黒帯が映る。** `#rec-caption.empty` の規則はあったのに
   **生成時に付けていなかった** → `buildOverlay` で最初から付ける（v54）

## 6-1. 音（v56〜v58 で入れた）

| | |
|---|---|
| ナレーション | VOICEVOX ずんだもん・5行・23.6秒（行間 0.6秒 ×4 で 26.0秒） |
| BGM | のんきな日常（DOVA-SYNDROME / Regu）。既定 -20dB |
| SE | tap.wav を**タップ6箇所**に。既定 -8dB |
| クレジット | `VOICEVOX:ずんだもん` を焼き込み＋投稿文にも入る |

**誤読を1件つぶした。** 「書き下し」を **カキオロシ**と読んでいた（正しくは かきくだし）。
原稿を「かきくだし」と仮名で書いて回避。`narrate.py` は行ごとに読み仮名を出すので、
**音を聞く前に目で確かめる**こと。目録は `narration/READINGS.md`。

**SE が 0 箇所だったのを直した（v57）。** 原因は2つ:

- `mux.mjs` は `['click','clickBond','button','undo']` の型にしか SE を置かない
- `read` は4回タップしても記録が1件なので、それだけでは1回しか鳴らない

→ **`tap()` の中でタップ1回ごとに `'click'` を出す**ようにした。
アクション単位の記録は先頭に残るので、`--trim=auto` の頭合わせは狂わない。

**字幕とクレジットが重なっていたのを直した（v58）。**
クレジットは `h*0.885`（＝下から 11.5%）に焼かれるのに、字幕が下から 8% だった。
字幕を 14% へ。**Instagram / TikTok のプレイヤーは下部をUIで覆う**ので、どのみち上げたほうがよい。
