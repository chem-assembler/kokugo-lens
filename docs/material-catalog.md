## 0. この台帳の前提（読む前に必ず）

### 0.1 著作権 — 何を集めて、何を集めていないか

| 集めたもの | 集めていないもの |
|---|---|
| **白文（原文の漢字列）** … 古典中国語の原文は著作権が切れている（パブリックドメイン） | **訓点**（返り点・送り仮名） |
| **事実情報** … 作品名・篇名・作者・時代・詩形 | **書き下し文** |
| **取得元URL** | **現代語訳・注釈・語釈** |
| 句法・定番度の欄（**当方の分析**であって転記ではない） | 教科書・参考書・問題集からの一切の転記 |

**訓点・書き下し・意味はアプリ側で自作する。** 現代の編者が付けた訓点や書き下しは編者の著作物に
なり得るため、この台帳には一切入れない。設計書 §2 原則3 の方針をそのまま適用している。

### 0.2 取得元

- **zh.wikisource.org（維基文庫）** … 本台帳のほぼ全件。安定して全文が取れる
- **ctext.org（中國哲學書電子化計劃）** … 韓非子・難一 の1件のみ。
  **ページによっては人間確認（CAPTCHA）画面が出る**。突破は行わず、その場合は Wikisource に切り替えた
- 各行の出典URLは §7 に作品単位でまとめてある

### 0.3 字体の方針

アプリは日本の新字体で表示する（學→学・國→国）。この台帳は**取得元の字体のまま記録**し、
新字体化が必要な行には「字体」欄に印を付けた。凡例:

- **［変換要］** … 常用漢字表の新字体に置き換える字を含む（學→学・爲→為・說→説 など）
- **［異体］** … 新旧の関係ではなく異体字・別字の関係。**置き換えると原文と別字になる**ので要判断
  （楯／盾・靑／青・蹞／跬・螾／蚓・无／無・凋／彫 など）
- 印なし … そのまま出せる

### 0.4 行の切り出し方針

アプリは **1問＝1文**。8〜15字程度で意味が完結する行を優先して切り出した。
対句は上下を別行にしてある（「学而不思則罔」と「思而不学則殆」を2問にする）。
漢詩は1句＝1行（五言5字・七言7字）で、返り点の練習単位としてそのまま使える。

### 0.5 句法タグは `kanbun.js` の語彙に合わせてある

`kanbun.js` の `KUHO_DIFF` が持つ11個のタグをそのまま使う。台帳の「句法」欄はこの ID で書く。

| タグ | 意味 | 難度 |
|---|---|---|
| `hitei` | 否定（単純・二重・部分） | 1 |
| `shieki` | 使役 | 2 |
| `ukemi` | 受身 | 2 |
| `gimon` | 疑問 | 2 |
| `eitan` | 詠嘆 | 2 |
| `sentaku` | 選択 | 2 |
| `hango` | 反語 | 3 |
| `hikaku` | 比較 | 3 |
| `katei` | 仮定 | 3 |
| `gentei` | 限定 | 3 |
| `yokuyo` | 抑揚 | 4 |

**再読文字と置き字はタグではない。** データ構造側で表す（再読文字＝ `reread: {first, second}`、
置き字＝ `role: "placed"`）。ただし素材選びの観点としては重要なので、本台帳では
「句法」欄に `[再読:未]` `[置字:於]` の形で併記する。

## 1. 逆引き索引 — 句法から題材を引く

### 8.6 句法カバレッジの現状

| 句法 | 素材の量 | 状態 |
|---|---|---|
| `hitei` 否定 | 極めて豊富（二重否定・部分否定・禁止も揃う） | 十分 |
| `hikaku` 比較 | 豊富（不如・莫如・於・逾） | 十分 |
| `gentei` 限定 | 豊富（唯惟独只但纔徒＋耳而已矣爾） | 十分 |
| `hango` 反語 | 豊富（不亦乎・焉安・何之有・何為・豈哉・孰・庸） | 十分 |
| `gimon` 疑問 | 豊富 | 十分 |
| `katei` 仮定 | 豊富（若如苟雖則微向） | 十分 |
| `eitan` 詠嘆 | 十分（哉夫矣嗟夫噫嗚呼悲夫宜乎） | 十分 |
| `shieki` 使役 | 十分（使令＋使動用法の引っかけ付き） | 十分 |
| `ukemi` 受身 | 十分（見〜於・見・被・為〜・於） | 十分 |
| `sentaku` 選択 | 十分（寧A無B・与其A寧B・二者択一の3型） | 十分 |
| `yokuyo` 抑揚 | 十分（且〜況〜乎／尚〜況〜乎／且＋反語／況単独で6行） | 十分（**史伝から取るのが正解**） |
| 部分否定 | 十分（不必不如師・師不必賢於弟子・何必） | 十分 |
| 再読文字9字 | 全字に実例あり（盍・宜・須が各1〜2例と少ない） | ぎりぎり十分 |
| 置き字 | 而・於・矣・焉・也・乎 は豊富。**「于」だけ S-12 / S-53b の2例と少ない** | 「于」要補充 |

**残る唯一の穴は置き字「于」**。「於」に比べて用例が極端に少なく、S-12（吾十有五而志于学）と
S-53b（塞于天地之間）の2行しかない。詩経・尚書まで下りると増えるが高校範囲外なので、
**孟子・論語の引用部からもう1〜2行拾うのが現実的**。

**盍・宜・須の再読文字も各1〜2例**しかない。これらは句法クイズで繰り返し出すことになるため、
同じ字を別の作品からもう1例ずつ確保しておくと安全（例: 盍は論語 公冶長のほかに孟子・戦国策に散在する）。

### 8.7 このカタログの使い方（次の作業）

1. **`kuho.json` を先に作る**（設計書 §7 の方針＝句法データを先に作り、訓点問題はそれを消費する）。
   §1 の逆引き索引がそのまま句形の型 → 例文ID の対応表になる
2. 訓点・書き下し・意味は**この台帳を見ながらアプリ側で自作**する。台帳には入れない
3. 投入時は `difficulty()` が自動計算するので `level` は手で書かない（設計書 §4.4）
4. 二重帳簿テスト（`kakikudashi` と `toKakikudashi()` の一致）で全問を機械検証してからコミットする
