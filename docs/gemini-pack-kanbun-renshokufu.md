# Gemini 依頼パック: 熟語返り（連読符・ハイフン）の実例を探す

## これは何の作業か

漢文学習アプリ **「返り点でみる漢文」**（https://koku.schoollenz.com/kanbun/ ／ 現在64問）に、
**熟語返り（連読符・ハイフン）を使う問題を1〜3問足したい**。そのための**白文と訓点の実例探し**。

熟語返りとは、**二字以上の熟語へ返るときに、熟語をハイフン（連読符）でつないで一語として扱う**書き方。

```
撃二-破 敵軍一     →  敵軍を撃破す
```

返り点は熟語の**先頭字だけ**に付け、つないだ二字は途中で切らずに続けて読む。

### なぜ困っているか

- アプリの**判定エンジンは熟語返りに既に対応済み**（`join` フラグ。回帰テストにも
  「熟語返り（ハイフン）: 撃二-破敵軍一」が入っていて合格している）
- ところが**実際の問題データ64問には熟語返りが1問もない**。テストにあるのにデータに無い、という不整合
- 探したが、**「この白文に、この訓点が標準的に付く」と自信をもって言える実例が見つからなかった**
- **推測で訓点を作ると、このアプリが守ってきた「テストが仕様の正」「推測で埋めない」という原則を破る**ことになるので、保留にしてある

**この作業が Gemini に向いている理由**: 判断より事実収集が主で、
「実際の教材でどう訓点が付いているか」を確かめる調べ物だから。

---

## 絶対の制約

- **市販の教科書・参考書・問題集の本文や解説を転記しない。** 記録するのは
  **白文（漢字列）と、返り点の付き方という事実**、そして**どの資料のどこで確認できるかというポインタ**だけ
  - 古典中国語の原文（白文）自体はパブリックドメインなので問題ない
  - **編者が付けた訓点は編者の著作物になり得る**。だから「A社の教科書ではこう」と転記するのではなく、
    **複数の資料で共通している標準的な形**を事実として記録する（下記「報告の形」を参照）
- **推測を事実として書かない。** 裏が取れないものは「未確認」と明記して分ける。
  **確実な1件のほうが、あやしい5件より価値がある**
- 現代語訳・書き下し文は不要（アプリ側で自作する）

## 探してほしいもの

### 必須の条件

1. **白文が古典（パブリックドメイン）であること**。中国の古典でも日本漢文でもよい
2. **8〜15字程度で意味が完結する短い文**（アプリは1問＝1文。20字を超えると使えない）
3. **熟語返り（連読符）が実際に使われる形であること**
4. **その訓点が標準的だと確認できる根拠があること**（複数資料で一致、など）

### いちばん確実な当て（優先順）

| 優先 | 当て | なぜ効くか |
|:--:|---|---|
| **1** | **漢文の文法解説サイト・訓点の解説記事** | 連読符の説明には**必ず例文が付く**。「ハイフン」「連読符」「熟語に返る」で検索すると、例文つきの解説が出る。**ここから始めるのが最短** |
| 2 | 大学の漢文・中国文学の授業資料（PDF） | 訓読法の講義資料に、返り点の階層と連読符の例が体系的に載っていることがある |
| 3 | 国語教育・漢文教育の論文 | 訓点の指導法を論じたものに実例が引かれる |
| 4 | 日本漢文のテクスト（`https://kambun.jp/`） | このサイトは訓点つきの本文を翻刻している。実際の訓点が見られる |

> **1 を一巡してから 2 へ進むこと。** 解説記事の例文は「連読符を説明するために選ばれた例」なので、
> 標準的な形である可能性が高い。原典から探すと、そもそも連読符が使われている箇所を
> 見つけるところで詰まる。

### よく挙がる候補（裏取りの出発点として。**そのまま採用しないこと**）

次のような形が連読符の例として挙げられることがある。**実在と標準性を確かめてほしい**。

- `撃二-破 敵軍一` … アプリの回帰テストに入っている形。ただし**出典が特定できていない**
- `与二父老一約-法三章` … 史記 高祖本紀「約法三章」。**約-法 とつなぐ形があるか**
- `不レ可二勝-数一` … 「勝げて数ふべからず」。勝数 を熟語として扱うか
- 「先-生」「天-下」など二字熟語へ返る一般形

## 報告の形

`docs/material-renshokufu.md` として、次の形でまとめてほしい。

```markdown
## 確実なもの（複数の資料で一致）

### 1. <白文>

- 白文: 撃破敵軍          ← 返り点・送り仮名なしの漢字列
- 出典: <書名・篇名>・<作者>・<時代>
- 訓点: 撃 に 二、破 との間に連読符、敵軍の「軍」に 一
        （どの字にどの返り点が付き、どこに連読符が入るかを文章で説明する）
- 読み順: 敵 → 軍 → 撃 → 破   ← 何番目にどの字を読むか
- 根拠: <確認できた資料のURLや名称を2つ以上>
- 備考: 新字体への変換が要る字があれば書く

## あやしいもの（1つの資料でしか見ていない）

（同じ形式で。**必ず「確実なもの」と分けること**）

## 見つからなかったもの

（何を探して、なぜ見つからなかったかを書く。これも成果です）
```

## 参考: このアプリのデータの形

見つけた実例が実際にどう入るかの参考（**この形で書いて提出する必要はない**。上の報告の形でよい）。

```js
{
  tokens: [
    { c:'撃', yomi:'う', okuri:'チ', join:true, mark:[{lv:1,n:2}] },  // 二 ＋ 連読符
    { c:'破', yomi:'やぶ', okuri:'ル' },                              // 連読符でつながる後続字
    { c:'敵', yomi:'てき' },
    { c:'軍', yomi:'ぐん', okuri:'ヲ', mark:[{lv:1,n:1}] }            // 一
  ],
  order: [2, 3, 0, 1]      // 敵 → 軍 → 撃 → 破
}
```

`join: true` を付けた字と、その次に読む字が**連結して一語として読まれる**。
返り点は先頭字（撃）にだけ付く。

## 期待する成果

- **確実なもの 1〜3件**あれば十分。0件でも「探したが無かった」という報告に価値がある
- 数を増やすより、**1件を確実にする**ことを優先してほしい
- 「連読符はそもそも現代の教材ではあまり使われない」といった**事実が分かった場合、それも成果**
  （その場合、アプリ側は「テストにはあるがデータには入れない」と正直に記録して閉じる判断ができる）
