# 国語レンズ（KokugoLenz）

SchoolLenz の第3の教科サブブランド。公開予定 URL: **koku.schoollenz.com**（DNS・Pages は未設定）。

## 構成

- ルート `index.html` … 国語レンズのハブ（アプリ一覧。自己完結・外部アセットなし）
- **`/kanbun/`** … 返り点でみる漢文（第1弾アプリ）
- `DESIGN_kanbun.md` … 設計書（決定事項・データモデル・アルゴリズム・実装順序の正）
- `PUBLISH_CHECKLIST.md` … 公開手順（GitHub Pages ＋ koku.schoollenz.com）
- `docs/` … 題材選定の資料（下記）

## 返り点でみる漢文 `/kanbun/`

| ファイル | 責務 |
|---|---|
| `kanbun.js` | 中核ロジック（DOM 非依存）。読み順計算 `readOrder` / 書き下し生成 `toKakikudashi` / 採点 `grade` / 難易度 `difficulty` / 仮名正規化 |
| `game.js` | 訓点モードの UI（縦書き描画・訓点パレット・ライブ書き下し・3モード・誤答再生アニメ） |
| `kuho.js` + `kuho.html` | 句法クイズ（3形式） |
| `texts.json` | 問題データ（トークン列・訓点・正解の読み順・書き下し）。現在28問 |
| `kuho.json` | 句形の型データ（35型・11カテゴリ）。`node kanbun/kuho-check.js` が検査 |
| `test.html` + `tests.js` | 回帰テスト。**コミット前に全合格必須**。`node kanbun/tests.js` でも走る |

## 題材選定の資料 `docs/`

| ファイル | 中身 |
|---|---|
| `material-catalog.md` | **白文素材台帳**。PD の一次テクスト（ほぼ全件 Wikisource）から約610行・約100作品。句法逆引き索引つき。訓点・書き下し・現代語訳は収集していない（アプリ側で自作するため） |
| `exam-kanbun-sources.md` | **入試出典データ**。共通テスト/センター1979〜2026、東大2000〜2026、東北大2015〜2026、早稲田2020〜2026、私大の漢文有無。事実データのみで問題本文は含まない |

**この2つの使い方**: `exam-kanbun-sources.md` の優先題材リストで「何を入れるか」を決め、
`material-catalog.md` の行IDで「その白文を引く」。訓点と書き下しは自作し、
`tests.js` の二重帳簿検査（訓点→読み順→書き下し）を必ず通す。

起動: リポジトリルートでローカルサーバーを立てる（例: `python -m http.server 8138` →
`http://localhost:8138/kanbun/`）。file:// 直開きは texts.json の fetch が失敗する。

## 次にやること（要判断・2026-08-05 時点）

**題材まわりで判断が要るもの**（`docs/material-catalog.md` §8 に詳細）

1. **偶成「少年老い易く…」の帰属**。朱熹作の一次典拠が取れず、近年は仮託説が有力。
   収録済み2問（`shonen-1` / `shonen-2`）の出典表記を「朱熹（伝）」に改めるか、差し替えるか
2. **底本と教科書通行形のずれ7件**（静夜思「牀前看月光」vs 通行「明月光」など）。どちらを採るか
3. **異体字12件**は機械変換不可（楯／盾、亡／無、女／汝など）。個別に判断が要る
4. **日本漢文がゼロ**。入試の成長トレンド（共通テスト2年連続・早稲田は2023以降シフト）に対し
   現在の `texts.json` に日本漢文が1問もない＝最大の空白

**入試データから見えた実装の含意**（`docs/exam-kanbun-sources.md` §2-7）

- **L5（白文のみ）は東北大の看板設問そのもの**（第四問②が訓点省略の白文書き下し）。優先度を上げてよい
- **L3（返り点を打つ）は學習院・文と早稲田（文・法・教育・商）の返り点記述に直接対応**
- 共通テストの最頻は明清の筆記（随筆）26件で、史伝は6件のみ。
  「受験漢文＝唐宋の史伝」という思い込みで題材を選ぶと的を外す

## 重要ルール（化学レンズと同じ規約）

- 全ファイル **UTF-8（BOMなし）**。コミット前に Shift_JIS 誤解釈由来の化け文字がないか確認
  （検査パターンの文字自体をファイルに書くと自己検出するので、パターンは chem の CLAUDE.md を参照）
- **このリポジトリでは化け検査が誤検出する**。検査パターンに使う文字はどれも実在の漢字で、
  漢文の作品名・人名に正当に現れる（実例: `彪邨文集`＝岡直養の日本漢文集。「邨」は「村」の異体字）。
  **一致したら機械的に直さず、前後を読んで実在の漢字かどうかを必ず judge すること**
- 採点は**訓点の表記ではなく読み順**で行う（レ点でも一二点でも、読み順が合えば正解＝ variant）
- バージョン `vNN` はコミットごとに `kanbun/index.html`・`kanbun/test.html` のキャッシュバスター＋表示を同時更新
- 1修正=1コミット。ブラウザで実機検証し、検証内容をコミットメッセージに記録
- 訓読には流派差があり正解が一意でない（設計書 §4.3）。失敗例を見つけたらテストを足して直す＝**テストが仕様の正**
