# Gemini 依頼パック: 句法4型の白文の実例を探す

## これは何の作業か

漢文学習アプリ **「返り点でみる漢文」**（https://koku.schoollenz.com/kanbun/ ／ 現在78問）の
句法クイズは **38型**を収録している。そのうち **4型だけ、練習に使える白文の実例が無い**。
その**白文探し**をお願いしたい。

### なぜ困っているか

- 句法クイズの出題自体は型データだけで動くので、**実例が無くても出題はできている**。
  無いのは「この型を実際の文で練習する」ための橋渡し
- 手元の白文台帳（`docs/material-catalog.md` 約510行・`docs/material-minqing.md` 約70行）を
  この4型で検索したが、**該当する行が1つも無かった**
- **推測で白文と訓点を作ると、このアプリが守ってきた「推測で埋めない」という原則を破る**ので保留にしてある

**この作業が Gemini に向いている理由**: 判断より事実収集が主で、
「その句形が実際に使われている短い原文はどれか」を探す調べ物だから。

---

## 絶対の制約

- **市販の教科書・参考書・問題集の本文や解説を転記しない。** 記録するのは
  **白文（漢字列）と、返り点・送り仮名の付き方という事実**、そして**どの資料で確認できるかというポインタ**だけ
  - 古典中国語の原文（白文）自体はパブリックドメインなので問題ない
  - **編者が付けた訓点は編者の著作物になり得る**。「A社の教科書ではこう」と転記するのではなく、
    **複数の資料で共通している標準的な形**を事実として記録する
- **推測を事実として書かない。** 裏が取れないものは「未確認」と明記して分ける。
  **確実な1件のほうが、あやしい5件より価値がある**
- 現代語訳・書き下し文は不要（アプリ側で自作する）

## 探してほしい4つの句形

### 1. 全部否定（副詞＋不）

- 型: `常 不 A` ／ 読み: **つねニAセず**（いつもAしない）
- 目印: 常不・必不・尽不・倶不 のように、**副詞が「不」の上に来る**
- **部分否定と紛らわしいので、それこそが探す理由**。部分否定は `不 常 A`＝「つねニハAセず」
  （いつもAするとは限らない）で、副詞と「不」の順が逆になる
- 部分否定のほうは実例を持っている（韓愈『師説』「弟子不必不如師」）。
  **欲しいのは逆順のほう**

### 2. 命令の動詞による使役

- 型: `命 A B` ／ 読み: **AニめいジテBセしむ**
- 目印: 命・勧・召・教・遣 など、**それ自体が命令や依頼を表す動詞**が使役の意味を作る
- 「使」「令」を使う基本形の実例は持っている（『戦国策』「天帝使我長百獣」など）。
  **欲しいのは「使・令を使わずに、命じる動詞で使役になる」形**

### 3. 詠嘆「豈不 A 哉」

- 型: `豈不 A 哉` ／ 読み: **あニAセずや**（なんとAではないか）
- **反語の「豈〜ンや」とは別物**。反語は「どうしてAだろうか、いやAでない」と打ち消すが、
  こちらは**感嘆**（「なんとAなことよ」）で、意味は肯定になる
- 反語のほうは実例を持っている（『列子』「其子豈遽善游哉」など）。
  **欲しいのは感嘆のほう**。「豈不」と「哉／乎」が揃う形

### 4. 詠嘆「何 其 A 也」

- 型: `何 其 A 也` ／ 読み: **なんゾそレAスルや**（なんとAなことよ）
- 目印: 「何其」が並び、文末が「也」または「哉」
- これも疑問の「何ゾ」（理由をたずねる）と紛らわしい。**答えを求めていない感嘆のほう**が欲しい
- **手がかり**: 『論語』子罕に「何其多能也」がある（大宰が子貢に問う場面）。
  ただし**直前が「夫子聖者与」という問いなので、詠嘆なのか疑問なのか当方では確定できていない**。
  この一文を採るなら、**詠嘆として扱うのが標準かどうか**まで確かめてほしい。
  確定できないなら、疑問と紛れない別の実例のほうがありがたい

## 必須の条件

1. **白文がパブリックドメインの古典であること**。中国の古典でも日本漢文でもよい
2. **4〜15字程度で意味が完結する短い文**（アプリは1問＝1文。20字を超えると使えない）
3. **その句形が実際に使われている形であること**（上の「紛らわしい相手」と取り違えないこと）
4. **その訓点が標準的だと確認できる根拠があること**（複数資料で一致、など）

## あると嬉しい条件

- **共通テストや二次で出る作品から取れること**。調査したところ、共通テストの最頻ジャンルは
  **明清の筆記（随筆）26件**、次いで詩と詩話18件で、史伝は6件しかない。
  「受験漢文＝唐宋の史伝」は実態と違うので、**明清の筆記や詩話は特に歓迎**
- 有名で、生徒が「聞いたことがある」文であること
- すでに収録済みの作品（論語・孟子・韓非子・戦国策・史記・列子・荘子・礼記・荀子・
  聊斎志異・夢渓筆談・五雑組・履園叢話・池北偶談・日本外史）から取れると、
  出典の説明を使い回せて助かる

## 報告の形

型ごとに、見つかった候補を次の形で書いてほしい。**1型につき2〜3件**あると選べて助かる。

```
## 型: 全部否定（常 不 A）

### 候補1
- 白文: （漢字だけ。句読点は入れてよい）
- 字数: 
- 出典: 作品名・篇名（できるだけ細かく）
- 原文の所在: Wikisource などの URL、または「中国哲学書電子化計劃 の◯◯」のような具体的な位置
- 返り点の付き方: 「Bの字からAの字へ返る」のように**言葉で**説明する（記号の図は不要）
- 読み方（送り仮名の要点）: 「常＝つねニ、不＝ず」のように、**その句形の目印になる字の読みだけ**
- 標準性の根拠: どこで確認したか。複数の資料で一致したならそう書く
- 確度: 確実 / たぶん / 未確認
```

### 見つからなかった場合

**「見つからなかった」も価値のある報告**なので、そう書いてほしい。
そのとき、**どこを探したか**（どのサイト、どの作品、どんな検索語）を残してもらえると、
次に探すときに同じ場所を掘らずに済む。

とくに「全部否定」は、**そもそも短文で成立する実例が乏しい可能性**がある
（副詞＋不の形自体は多いが、4〜15字で意味が完結する切り出しが難しい）。
その見立てが正しいかどうかも知りたい。

## 参考: このアプリが白文をどう扱うか

- 版本の異同は**日本の教科書の通行形**を採る（底本の形は注記に残す）
- 字体差は通行字体に統一する（爲→為・將→将・學→学など）
- **読みが変わる別字（亡＝無「なし」、女＝汝「なんぢ」）は原文のまま残す**。読めないこと自体が学習内容
- 出典の帰属が疑わしいものは「（伝）」と表記して注記で説明する
