# 字の働きの統一規則

750問の前半・後半の下書きを統合した10区分の暫定基準。品詞名の一覧ではなく、その文で字が担う働きを示す。名詞化・提示・呼格などには専用区分がないため、以下の約束で一つに決める。高校生にはまず「何が、どうする、何を」と文の中心を見つけ、次に条件・相手・語気を分ける手順で説明する。区分そのものはレビュアーの確認待ちである。

## 判定する順序

1. 問題の同じ位置の `imi.json`、tokensの読み・送り・再読・join・placed、書き下し、現代語訳、`kuho.json` の該当型と問題のkuhoを照合する。読みや意味の異なる同字を、字面だけで統一しない。
2. `role: placed` の字だけを「置き字」にする。読まないように見えるという判断でplacedでない字を置き字に逃がさない。
3. joinはエンジンと同じく次の読み字（置き字は飛ばす）との連結。連結した字は同じ働き。孰与など二字で一つの読み・意味になる語、固有名詞・通常の名詞熟語は語全体の働きを各字に付ける。
4. 句全体が名詞化されても、内部で対象・相手を持つ動詞の述語性は原則として残す。所・者に名詞化した句全体の主語・目的語等を付ける。一字自体の意味が「行うこと」「理由」「満足」等の名詞内容なら、その名詞の役割を採る。意味欄の語義に反する読み替えはしない。
5. imi・書き下し・訳の説明に差がある場合は、意味欄で語義を絞り、訓点どおりの構造を選ぶ。解釈差は隠さず報告し、元のtexts・imi・kuhoはこの作業で書き換えない。

## 10区分の範囲

| 値 | この台帳での意味 |
|---|---|
| 主語 | 動作・状態の主、存在する物、または名詞化した話題の中心。呼びかける人物も暫定的に含む |
| 述語 | 動作・状態・存在・比較を述べる中心。名詞で「何であるか」を述べる場合も含む |
| 目的語 | 実質動詞の働きかける対象。前置された対象、使役の対象も含む |
| 補語 | 動作の相手・起点・到達点・通過点・比較基準・結果、および前置詞に導かれる名詞 |
| 修飾語 | 名詞の限定、時・場所・程度・様態などの状況、以下で指定する提示・構造・語調の仮置き |
| 前置詞 | 名詞・名詞化内容を導いて、手段・理由・資格・対象・相手・起点等の関係を示す字 |
| 助動詞 | 述語に否定・可能・受身・使役・志向・義務・断定・評価等を添える字 |
| 接続 | 二つの節や並列項を結び、順接・逆接・理由・仮定・選択・展開等の関係を表す字 |
| 置き字 | tokensで明示的に `role: placed` の字だけ |
| 文末の助字 | 読んで断定・疑問・反語・詠嘆・限定等の語気を結ぶ字。部分句の末尾と独立した感動句の語気も暫定的に含む |

「は」だから主語、「をや」だから目的語とは決めない。前に出された話題を実質動詞がどう受けるかを見る。存在の有・無の内容は主語、「持つ」の有の対象は目的語。使役の兼語は、動作主でもあるが使から見た対象を優先して目的語にする。前置された場所の自由な状況説明は修飾語、動詞が要求する起点・行先・相手は補語とする。書き下しの「に」だけでは区別しない。

## 字・用法ごとの約束と、両便の採否

### 所・者・名詞化

両便の共通方針を採用する。名詞化は専用ラベルがないので、句全体の役割を所・者に付ける。「欲せざる所」は施す対象として目的語、「心の欲する所に」は補語、「魚は欲する所なり」は述語。同じ所でもラベルが割れるのは役割が異なるためで、統一漏れではない。

為A所Bの所は名詞化だけでなく受身構文を組み立てる標識として助動詞。Bの動詞は述語、AはBの動作主として主語にする。為・所をすべて名詞句へ分解する案は採らない。両便ともこの扱いで一致している。

所以は理由・用途を表す一語とし、二字とも句の役割。所謂は「いわゆる」の二字で修飾語。昔者・今者は時の修飾語。者が「は」と読む主題標識でも、名詞句の代表として主語を引き継ぐ。人物名＋なる者の名は者への修飾語、知者・仁者など語になった人物名詞は語全体の働きにする。矣がimiで「こと」と名詞化を表す `airen-mube` は主語とする。

### 之・其・自・相

両便の共通方針を採用する。之が「これ・それ」を指す場合は動詞との関係に応じ目的語・補語・主語。「ゆく」は述語。読む連体・主格・対象関係・前置標識の之は、助詞区分がないため構造を整える修飾語に仮置きする。placedなら語義にかかわらず置き字。目的語前置の標識を、実際の対象である代名詞と教えない。

其が「その人が」なら主語、「その〜」なら修飾語。自は起点なら前置詞、「自然に・自分で」なら修飾語、「自分を・自分に」なら目的語・補語。相は「互いに」なら修飾語、「私を」なら目的語、鑑定するなら述語、人名や宰相なら名詞句の役割とする。

### 猶・盍・再読文字

再読の未・将・当・応・宜・須は助動詞。再読の且も直前・将来を添える助動詞。将軍・当世・須臾・応ふ・宜なるかな等の別用法には、この規則を広げない。

猶は前半の**再読の比況＝述語**を採る。「なお〜のごとし」という二つの読みを合わせて「〜と同じだ」と判断を述べる。一読の継続・抑揚の「なお」は後続を添える修飾語。猶予は二字の動詞として述語。これで両便の文脈上の差を説明できる。

実データを調べると、前半の比況の猶は4字すべてrereadがあり、後半の7字にはrereadが一つもない。したがって、指示書の例にある「後半の再読の猶を修飾語」は今回の入力には実在しない。`shiki-hihitsuji` の猶はimi「同じように」の一読で、是が「かくのごとき」の述語を担う。猶を全部同じラベルに変更しない。盍は前半の助動詞を採り、疑問・否定・勧誘を一字で添えると説明する。

### 与

比較選択の**与其は後半の接続**を採る。前半は前置詞だったが、「AするよりはBする」という節の選択を結ぶ点を教える方が、同伴・相手を導く与との区別が明確になる。前半4字を変更する。

名詞を同格に並べる与は接続。特定の同伴・比較相手を導く与は前置詞（相手が文脈から明らかで省略されても同様）。相与に／ともにと動作の様子だけを添える語は修飾語。与える・味方する・一緒にするは述語。疑問の与は文末の助字。孰与・孰若は二字の比較疑問の述語。「与」の一字を「と」と読む前置詞に分けない。

### 以・於

両便の用法別の区別を採用する。手段・根拠・状態・資格・判断対象を導く以は前置詞。「以てす」「以てするは」でも、imiが手段や根拠を示すなら前置詞を保つ。手段の名詞が省略された `mq-gozasso-madoi` の最初の以も前置詞。節全体を理由として結ぶ以、順接・経緯をつなぐ以は接続。語調を整える以は修飾語への仮置き。

無以の以はimiの「手だて」という名詞内容を採り、無の存在内容の主語。単独の以が「理由」なら同じく主語。所以・以為・是以は二字の意味を保って語全体の働き（理由の名詞、判断の述語、因果の修飾表現）にする。以是と是以を混同しない。`sekiheki-ippun` の以はimiが「とどまる」の実質動詞なので述語。於はplacedなら置き字、読むなら前置詞。於是はこの入力ではjoinがなく、読む於＋是の前置詞・補語に分ける。二字で「そこで」と訳せるだけでは熟語と決めない。

### 為・是・非

両便の共通方針を採用する。断定の為・是は名詞述語を助ける助動詞、名詞部分は述語。「なる・する・みなす」は実質動詞の述語。「ために」は前置詞、何為の「なぜ」は二字で修飾語、反語の「や」は文末の助字。為人は「人柄」の名詞として主語。為A所Bは為・所を助動詞、動作Bを述語。

「宋国の笑ひと為る」「若の笑ひと為る」は意味上は受身でも、imi・書き下しが示す「笑いものになる」の構成を保つ。為は述語、笑は結果の補語、宋国・若は笑への修飾語。受身の意味だけで全部を為所型にしない。是の指示代名詞・連体修飾・正しいという述語は断定と別。非は断定否定なら助動詞、「是か非か」の正誤判断なら述語。

### 無・莫・有・罔

存在する／しないものを述べる有・無・莫は述語。とくに**不存在を表す無不・莫能も述語を残す**方針に統一する。前半の無2字・莫2字を助動詞から変更する。無不の「不」が下の「しないもの」というまとまりを作り、無はその不存在を述べる。後半の `boufu-nusumazaru` と同じ基準であり、否定が単純に打ち消し合うとは説明しない。莫能は「できるものがない」、莫若・莫如は「及ぶものがない」と説明する。

禁止の無かれ・莫かれは助動詞。無改の動作否定、無論の不要も、imiどおり動作に添える助動詞。無貴無賎の「問わない」は独立した述語。無窮・無尽蔵は熟語全体の働きにする。罔は「くらし」なら述語、罔不の否定の構文標識は助動詞という両便の区別を保つ。全ての否定字を一律に処理しない。

### 也・句末の助字・発語

**主題を提示する也は後半の修飾語への仮置き**を採る。前半の該当7字を変更する。文全体の最後に見えても、imiが提示で、倒置された話題を添える働きならこの規則を優先する。読む也の断定・理由・疑問・詠嘆は文末の助字。者による名詞句の主題化とは表す階層が異なるため、同じ「は」の訳だけでは同一ラベルにしない。

乎・哉・耶・兮などは読む語気なら文末の助字。字列末だけでなく、引用や短い句の末尾も含む。耳・爾・已の「のみ」も限定の語気として含む（身体の耳、代名詞の爾、動詞の已は別）。文頭の嗟夫・嗟乎・噫・嗚呼は独立した感動句の語気として同区分へ仮置き。名が「文末」であることとの不一致は相談事項として残す。発語の夫は修飾語、話題を切り替える若夫の二字は接続。

### 後続動作を助ける字

欲の志向・直前、能・可・得の可能、易・難の難易、請の提案は助動詞。欲望そのもの、能力という名詞、得る・実現する、独立した可なり、相手に頼む請は実質的な述語や名詞句の役割を保つ。所欲の欲は対象を直接取る述語。肯は承知するという独立した判断の述語。

動作への評価「〜するに足る」は**前半の助動詞**を採る。後半 `touka-iunitarazu` の足1字を変更し、前半の謀る・辞するに足るとそろえる。量が足りる足は述語、身体の足や「満足」という名詞内容は格に応じる。堪はimiの「ふさわしい」という独立した判断を保って述語とする。

### 疑問熟語・数量・連体修飾・時

何如・如何・奈何・孰与・孰若は、処置・あり方・比較を問う二字の述語。内部に他の語が入る奈何も二字同じ。「何如のみ」と節が名詞化されても述語性は残す。前半 `mq-gozasso-tada` の何・如2字を修飾語から変更する。何為はimiが理由の「なぜ」なので二字の修飾語とする。何以は何を以ての補語・前置詞に分ける。

自由な数量句は数字を中心名詞への修飾語とする。五百金の五百は前半 `senju-shiba` の修飾語を採り、後半の購入場面2問4字を変更する。ただし数字全体が名詞述語（七百里など）をなすときは述語。一寸・一見・百聞・四体・百吏など、下書きで語として扱った語は語全体の働きを保つ。joinのある語を数字だけ分けることはしない。

「死んだ／生きた＋動物名」は後半の**状態による連体修飾**を採り、前半の死馬・生馬・死蚌・死鷸の状態字4字を修飾語にする。語となった生者・仁者等と、自由に動物名を限定する組合せを分ける。毎の「たびに」は時間・反復の修飾語にそろえ、後半 `kugatsu-2` の毎1字を接続から変更する。

名詞止めの詩は訳と前後の句で、省略された存在・見る等との関係を判断する。独立した景の中心は主語、次句の見る対象として明らかな月等は目的語、時・場所の設定は修飾語。見えないトークンは足さない。これは文脈による判断で、すべての名詞止めを主語へそろえる規則ではない。

## 制約とレビューしてほしい点

- 名詞化、主題提示、主格・前置標識、独立した感動詞・呼格の専用区分がない。修飾語／文末の助字／主語への仮置きは通常の意味より範囲が広い。
- 一字一値なので兼語・前置された話題・詩の連続句で兼務が落ちる。語のまとまり、字自体の機能、文全体の役割という階層も完全には分けられない。
- 無不の無を存在述語、罔不の罔を否定の助動詞に分ける語彙上の扱い、肯と欲、堪と足、於是と是以、数量熟語と自由な数量句の境界は、説明として妥当か確認が必要。
- `kosetsu-4` の雪はimi「雪」、書き下し「雪を釣る」、訳「雪の中で釣る」で、対象と場所の焦点が異なる。暫定的に書き下しの目的語を保つ。
- `shisetsu-kutou` の惑はimiの之が目的語前置を示すため目的語。訳の「解消されない」に引かれて主語へ変えない。`roshitsu-nanzo`・`rongo-iyashiki` の之の前置標識と「これ」の読み、`moshi-taikan-ame` の旱の主格説明、`torou-kaerimizu` の後之の場所／主格の説明にも解釈の境界が残る。
- `torou-isamuru` の死、`mq-etsubi-genka` の肖、`shungyo-2` の聞、`moshi-gi` の者、`sekiheki-fuyu` の渺について両便が挙げた訳・字義・構造の差も継続相談。ラベルだけで原文の解釈差を解決したとはしない。

## 検査と記録

`node kanbun/hataraki-check.js` は750キーの過不足、tokensとの長さ、10種の値、placedとの双方向一致、次の読み字とのjoin一致、指定6字の再読を検査する。不備は終了コード1。意味の正しさや上記の解釈差を自動で保証する検査ではない。`node kanbun/tests.js` からも同じ検査を呼ぶ。版は上げていない。

変更全件は作業場所の `hataraki-changes-final.jsonl`（id・0始まり位置・字・前後・規則・理由・imi・書き下し・訳・kuho）に保存。`hataraki-changes.jsonl` は検査で取り消した中間変更を含む追記型の履歴。`hataraki-distribution-before.tsv` と `hataraki-distribution-after.tsv` は全字種の分布、`hataraki-token-audit.jsonl` は全字照合表、`hataraki-priority-review.jsonl` は主要な多義字の判定根拠。`progress.jsonl` に指示名と保存済みIDを追記し、再実行では一致する保存済みIDを飛ばす。
