# Gemini 依頼パック: 漢和辞典の「日本語での用法」から、漢文で取り違えやすい意味を拾う（全4束）

## これは何の作業か

漢文学習アプリ **「返り点でみる漢文」**（https://koku.schoollenz.com/kanbun/）の読解の精度を上げたい。
生徒がよく誤るのは、**日本語でしか使わない意味を漢文に持ち込む**ことだ
（例: 「和」を「やまと」、「相」を「あいて」の意味に取る）。

添付の PDF は、ある漢和辞典のページを抜き出したもの。辞典には、日本だけで使われる意味・用法を
まとめた **赤い縦長の札「日本語での用法」** がある。**札はこちらで機械検出し、青枠で囲んである。**
各束の1ページ目が一覧（PDF のページ番号／辞典本体のページ番号／そのページの札の数／
アプリでよく使う字）になっている。

**この作業が Gemini に向いている理由**: 判断より読み取りが主だから。
札が付いている親字と、札の中で示される「日本だけの読み・意味」を拾えばよい。

---

## 絶対の制約

- **辞典の文章を書き写さない。** 辞典は市販の著作物。拾ってよいのは
  **親字・読み（《 》で示されるもの）・用例の語（二〜四字の熟語や地名など）だけ**。
  意味の説明は、**辞典の言い回しを使わず自分のことばで 30 字以内**にまとめる
- **推測を事実として書かない。** 札がどの親字のものか確信が持てない、字がつぶれて読めない、
  などは `"confidence": "低"` にして `note` に理由を書く。**空欄で出さず、必ず1行は返す**
- **そのページに印刷されていないことは、一語も書かない。** 自分の知識で補わない。
  `jp_readings` と `examples` は、**札の欄の中に実際に印刷されている語だけ**を、紙面どおりの字で書く。
  `gloss` も、その欄に書かれている意味だけを言い換える（よく知られた日本語の意味でも、欄に無ければ書かない）。
  1束目では「丁」で、欄に無い「少し・わずか（一丁前）」を書いた誤りがあった
- **`confidence` の基準**: `"高"` ＝ 欄の文字を最後まで読めて、全部を紙面と見比べた ／
  `"中"` ＝ 一部の字がつぶれている、または欄が次の段・次のページへ続いていて追い切れない ／
  `"低"` ＝ 親字の特定や欄の中身に自信がない。**全部を「高」にしないこと**
- **青枠が札でなかったら**（部首の札・挿絵・「使い分け」など）、`"not_label": true` で1行返す。
  逆に、**青枠のない「日本語での用法」札に気づいたら**それも1行返し、`note` に「枠なし」と書く

## 出してほしいもの（青枠1つにつき1オブジェクト・JSON配列で）

| キー | 中身 |
|---|---|
| `pdf_page` | 一覧に書いてある **PDF のページ番号**（束の中での通し番号ではない） |
| `body_page` | 辞典本体のページ番号（一覧に書いてある） |
| `headword` | 札が付いている**親字（見出しの一字）** |
| `not_label` | 青枠が「日本語での用法」札でなければ `true`。札なら省略 |
| `jp_readings` | 札の中で示される**日本だけの読み**（《 》の中身）の配列。無ければ `[]` |
| `jp_senses` | 日本だけの意味の配列。各要素は `{"gloss": 自分のことば30字以内, "examples": [用例の語を最大3つ]}` |
| `kanbun_caution` | **漢文を読むとき何に気をつけるか**を自分のことばで1文（40字以内）。例:「漢文の『相』は『たがいに・〜を』の副詞で、『あいて』の意味は無い」 |
| `confidence` | `"高"` / `"中"` / `"低"` |
| `note` | 迷った点・読めなかった字など。無ければ省略 |

### 出力例（架空の字で形だけ示す）

```json
[
  {"pdf_page": 350, "body_page": 202, "headword": "和",
   "jp_readings": ["やまと", "なぎ", "にぎ"],
   "jp_senses": [
     {"gloss": "日本・日本のものを指す", "examples": ["和歌", "和服"]},
     {"gloss": "風や波がおさまって静かな状態", "examples": ["朝なぎ"]}
   ],
   "kanbun_caution": "漢文の『和』は『やわらぐ・こたえる』で、日本を指すことは無い",
   "confidence": "高"}
]
```
