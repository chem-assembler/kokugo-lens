# 実例が1件しかない9型の白文 — 収集と検収の記録（進行中）

依頼パックは `docs/gemini-pack-kuho-9types.md`。
**ただし第1回は Gemini に投げず、こちら側で維基文庫の原文に直接あたって集めた。**

## なぜ自分で集めたか

前回（`material-kuho-4types.md`）で分かったのは、**報告のうち検収に耐えたのは半分**で、
落とした4件はどれも**原文にあたれば1回で分かる**種類の誤りだった（不在2件・句形違い1件・句読1件）。
訓点欄も4件中3件が誤っていた。つまり**この作業の実質は「原文にあたること」**で、
そこができるなら伝言を1回減らしたほうが速く、落ちる情報も無い。

**やり方**: `https://zh.wikisource.org/w/index.php?title=<頁名>&action=raw` で
**生のウィキテキストを取り、一字一句そのまま抜き出す**。整形済みの頁を要約させると
文字列が変形するので、必ず `action=raw` を使う。
（`ctext.org` は CAPTCHA で止まるので使わない。**CAPTCHA は突破しない**）

## 第1回（2026-08-13・v48）— 4問・3型

| 型 | 白文 | 出典 | 問題ID |
|---|---|---|---|
| 抑揚 `yokuyo-nao` | 蔓草猶不可除況君之寵弟乎 | 春秋左氏伝 隠公元年 | `saden-mansou` |
| 抑揚 `yokuyo-nao` | 布衣之交尚不相欺況大国乎 | 史記 廉頗藺相如列伝 | `kanpeki-fui` |
| 使役 `shieki-doushi` | 命子封帥車二百乗以伐京 | 春秋左氏伝 隠公元年 | `saden-shifu` |
| 受身 `ukemi-tokoro` | 先即制人後則為人所制 | 史記 項羽本紀 | `shiki-sakinzureba` |

**抑揚は 1件 → 3件**になり、しかも**「猶」の形と「尚」の形が両方そろった**
（型の名前は「A 猶 B、況 C 乎」なのに、それまでの唯一の実例は「尚」を使う文だった）。
使役・受身はそれぞれ 1件 → 2件。

### 原文の確認（すべて `action=raw` で取得した文字列そのまま）

| 白文 | 原文 |
|---|---|
| 蔓草猶不可除… | `蔓，難圖也。蔓草猶不可除，況君之寵弟乎？！` |
| 布衣之交尚… | `臣以爲布衣之交尚不相欺，況大國乎！` |
| 命子封… | `命子封帥車二百乘以伐京。` |
| 先即制人… | `吾聞先即制人，後則為人所制。` |

- **句読点はすべて `！` または `。`**。前回「？」で落とした詠嘆のような取り違えは無い
- 字体は `爲→為`・`國→国`・`乘→乗` を通行字体に直した（`kyujitai.js` の対応表に載っている）
- `蔓草…` の底本は `？！` の重ね。**反語まじりの詠嘆的な抑揚**だが、
  上に「猶」・下に「況〜乎」がそろうので抑揚として採る

### 訓点は自前で組んだ

- 蔓草猶不可除… … `不レ 可レ 除`（レ点の連鎖）。抑揚そのものには返り点が付かない
- 布衣之交尚… … `不二 … 欺一`。「相」を挟むのでレ点にはできない
- 命子封… … **一二点が2組**（`命二…封一` と `帥二…乗一`）＋ `伐レ 京`。
  2組は入れ子ではなく前後に並ぶだけなので、どちらも一二点でよい
- 先即制人… … `制レ 人`／`為二 人 所一レ 制`。**「一レ」の合字**は既存の
  `宅為人所奪`（`為二 人 所一レ 奪`）と同じ組み方をなぞった

4件とも `lane-verify.js` の二重帳簿（訓点→読み順→書き下し）を通し、
実機 L1 でタップして「○ 全部正しい順に読めました！」まで確認している。

### 原文の確認（`action=raw` の文字列そのまま）

| 白文 | 原文 |
|---|---|
| 非利不動… | `非利不動，非得不用，非危不戰。` |
| 非独政能也… | `非獨政能也，乃其姊亦烈女也。` |
| 豈不謬哉 | `乃引「天亡我，非用兵之罪也」，豈不謬哉！` |
| 大赦天下 | `是日，大赦天下。`（高祖本紀に4か所） |

- 詠嘆は**底本が「！」**であることを確かめてから採った（反語との別れ目はここ）
- 字体は `獨→独`・`戰→戦` を通行字体に直した。**`姊→姉` は対応表に無い**が、
  README の異体字の方針どおり通行字体に統一した（台帳の行ではないので表には足していない）
- 「非利不動」の三つ組は**「利・得・危」を名詞として読む**流儀を採り、
  「危ふきに非ざれば」と読む流儀を `acceptable` に入れてある

### 探し方（維基文庫の検索 API）

`insource:` で原文の文字列を直接探せる。**`prefix:` と組み合わせると収録済みの作品に絞れる**ので、
出典の説明を使い回せる範囲で探せる。

```
https://zh.wikisource.org/w/api.php?action=query&list=search
  &srsearch=insource:"豈不" prefix:史記/&srlimit=20&format=json&formatversion=2
```

**`OR` でつないだ複数の `insource:` は 0 件になる**（構文が通らない）。1語ずつ投げること。
これで史記23巻に「豈不」、14巻に「何其」があると分かり、卷007（項羽本紀）から採れた。

### 原文の確認（`action=raw` の文字列そのまま）

| 白文 | 原文 |
|---|---|
| 鷦鷯巣於深林… | `鷦鷯巢於深林，不過一枝；偃鼠飲河，不過滿腹。` |

  ただし多くは長い文の途中なので、10字で切れるこの1件は貴重

  markers に合わせて `必ず`・`尽く`・`倶に` を足した

## 詠嘆「何其A也」→ **(a) 1件のままにする**（2026-08-13・ユーザー判断）→ その後 v52 で2件になった

**底本の句読点で見るかぎり、「！」で終わる用例が見つからない。** 調べた範囲:

| 出典 | 用例 | 底本の句読 |
|---|---|---|
| 五代史伶官伝序 | 何其衰也 | **！**（＝いま収録している唯一の実例） |
| 史記 卷047 孔子世家 | 何其正也 ／ 汝來何其晚也 | ？ ／ ？ |
| 莊子 齊物論 | 何其无特操與 | ？（しかも文末が「與」） |
| 孟子 盡心上 | 此非吾君也，何其聲之似我君也 | ？ |
| 孟子 盡心下 | 而何其血之流杵也 | ？ |
| 論語 子罕 | 何其多能也 | ？（2026-08-12 に落としたぶん） |

史記は全巻で「何其」を含むのが14巻しかなく、そのうち通読したものはすべて疑問だった。

> **前提が変わった（v52）。** Gemini 経由で **底本が「！」の用例**（莊子 駢拇「天下何其囂囂也！」）が
> 見つかったので収録した。**(a) の規律はそのまま**で、単に素材が出てきただけ。
> (b)（規律をゆるめて「？」の用例も採る）に切り替える必要はもう無い。

二択を出して **(a) を採った**（ユーザー判断・「とりあえず」）。

- **(a) 1件のままにする** ← **これを採用。**
  これまでの規律（底本の句読点で疑問と詠嘆を分ける）をそのまま通す。
  「用例が無い」ことも一つの事実で、`何其衰也` が代表例として立派に働いている
- (b) この型だけ句読点の規律をゆるめる。「何其A也」は**中国語としては形の上で疑問文**なので
  近代の校訂者は「？」を打つが、**日本の訓読では詠嘆として教える**。この見方を採るなら
  孟子 盡心上「何其声之似我君也」（8字・魯の君の声を聞いた門番のことば）が採れる。
  ただし**疑問の型 `gimon-nanzo` との見分けが「？か！か」でなくなる**ので、
  型の note に見分け方を書き足す必要がある

**(a) は「とりあえず」の決着なので、(b) に切り替える余地は残っている。**
切り替えるときに要るものは上に全部書いてある（候補の白文・字数・出典・そのとき足す解説）。

→ **これで §2（実例が1件しかない型を厚くする）は打ち止め。**
9型のうち8型を2〜3件にし、残る1型は「素材が無い」という結論を根拠つきで残した。
