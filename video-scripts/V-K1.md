# V-K1 漢文は上から順に読まない（百聞は一見に如かず）

**国語レンズの1本目。** 台本 `kanbun/demos.json` の `kaeriten-hyakubun`、訓点モード L1。

## 1. なぜこの題材か

- **読み順が 百→聞→一→見→如→不 と最後に2つ戻る。** 読み順バッジが飛んで付き、
  左に書き下しが伸びる画が、**「漢文は上から順に読まない」という一点だけ**を
  説明ぬきで見せる
- **誰でも知っている慣用句**なので、冒頭でフックの説明が要らない（短尺は最初の1秒が勝負）
- **操作はタップだけ**＝失敗要素がほぼ無い。実収録の1本目に向く

## 4. 踏んだ穴（すべて実収録のコマで見つけた。読んでいるだけでは出ない）

1. **冒頭に別の問題が映る。** `applyState`（頭出し）が `delay` の**後**だったので、
   収録開始から2.2秒、既定で開く問題（衆狙皆怒・荘子）がそのまま映っていた。
   → `applyState` を delay の前へ（rec.js・v55）
2. **紙の左9割が白いまま。** 縦書きは右端から始まるのに `#stage` が横いっぱいに広がる。
   → `.rec-short #stage` に `justify-content` / `align-items: center`（v54）
3. **書き下し列の案内文が主役を食う。** ラベルと「（読む順に字をタップすると…）」が
   縦書きで長く伸び、見せたい書き下しと張り合っていた。**字を大きくして初めて目立った**
   → `game.js` が `.placeholder` を付け、CSS が落とす（v54）
4. **演技が始まるまで、文字の無い黒帯が映る。** `#rec-caption.empty` の規則はあったのに
   **生成時に付けていなかった** → `buildOverlay` で最初から付ける（v54）
